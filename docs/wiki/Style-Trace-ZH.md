# 风格描摹

**排列 → 风格描摹…**（Arrange → Style trace…）会把选中的图片重新绘制为 21 种风格之一的线条，可直接用于绘制：波浪线、螺旋、波纹、半色调圆、排线、点画、一笔画、流线、素描等。它也位于图片的右键菜单中，以及 **属性**（Properties）的 **图像**（Image）部分。它在 LightCreator、MillCreator、PenCreator 和 BaseCreator 中的用法相同。

## 分步说明

1. 选中一张图片，然后选择 **风格描摹…**（Style trace…）。
2. 选择 **风格**（Style）；其下方的一行文字会说明它绘制什么。有些风格有 **种类**（Kind）（例如点画可选点、短线或三角形）。
3. 调整风格的设置。预览会精确显示将放到绘图上的线条；它在后台计算，所以窗口不会卡住（旧线条在新线条准备好之前保持灰色）。按钮下方的一行文字会说明共有多少条线以及它们的总长度。
4. **色调**（Tone）：**黑点**（Black point）和 **白点**（White point）截去最暗和最亮的灰度，**伽马**（Gamma）提亮（大于 1）或压暗中间调，**描摹亮区**（Trace the light areas）交换暗部和亮部。
5. **放到图层**（Put on the layer）：程序会选择第一个绘制 **轮廓** 的空图层（填充图层会被跳过）；描摹会把该图层设为 *轮廓*（Outline）。请选择线宽不大于该风格线距的笔，否则线条会互相粘连。你可以从列表中选择其他图层。
6. **之后删除图像**（Delete the image afterwards）会在生成线条后删除图片。
7. **描摹**（Trace）把线条作为一个形状放到绘图上，替代图片的位置（随图片一起移动、旋转和缩放）。**编辑 → 撤销**（Edit → Undo）可将其撤回。

使用随机性的风格（点画、流线、素描、涂鸦、方块、针线、Truchet 拼贴）有一个 **随机图案**（Random pattern）编号：相同的编号每次都产生相同的线条，**换一个**（Another）会尝试另一个。

## 风格

| 风格 | 绘制什么 | 设置 |
|---|---|---|
| **波浪线**（Squiggle） | 一行行的线，图片越暗，波动越快越高。 | **线条间距**（Spacing of the lines）、**波高**（Wave height）、**每毫米波数**（Waves per mm）、**角度**（Angle）；种类：从边到边的行，或 **在白色处抬笔**（Lift the pen over white）。 |
| **锯齿**（Sawtooth） | 同样的行，画成锯齿形。 | 同波浪线。 |
| **弹簧**（Springs） | 一行行像拉开的弹簧一样的环，越暗越大。 | 同波浪线。 |
| **螺旋**（Spiral） | 从中心出发的一条螺旋线，在阴影处摆动更大（其他程序中的 *频率线*（Frequency lines））。 | **圈间距**（Spacing of the turns）、**波高**、**每毫米波数**；种类：波浪或锯齿。 |
| **波纹**（Waves） | 按暗度抬起的行，就像从侧面看到的地形；前面的行会遮住后面的内容。 | **线条间距**、**波纹高度**（Height of the waves）；种类：隐藏后面的内容，或完整绘制每一行。 |
| **半色调圆**（Halftone circles） | 圆形网格，圆的大小随色调变化，就像印刷的照片。 | **单元大小**（Cell size）、**最大圆**（Largest circle）、**环间距**（Spacing of the rings）、**角度**；种类：圆、环（用环填充）或螺旋。 |
| **蚀刻**（Etching） | 分层排线，就像老式版画：每深一级色调就增加一个方向的线条。 | **线条间距**、**色调级数**（Tone levels）（1 到 6）、**角度**；种类：直线或波浪线。 |
| **方块**（Squares） | 方块网格，方块层层嵌套，越暗越多。 | **单元大小**、**每个单元最多方块数**（Most squares in a cell）、**抖动**（Shake）（随机旋转）、**角度**。 |
| **针线**（Needles） | 网格上的短笔画，越暗越长。 | **单元大小**、**笔画长度**（Stroke length）、**角度**；种类：沿形状、按角度或随机。 |
| **Truchet 拼贴**（Truchet tiles） | 随机旋转的四分之一圆拼贴，越暗圆弧越多。 | **拼贴大小**（Tile size）、**每块拼贴最多圆弧数**（Most arcs in a tile）。 |
| **等值线**（Contour lines） | 亮度相等的线，就像地图上的等高线。 | **平滑**（Smoothing）、**色调级数**（2 到 40）。 |
| **希尔伯特曲线**（Hilbert curve） | 一条空间填充曲线，越暗转折越细密。 | **最小步长**（Smallest step）、**色调级数**；种类：一条线或 **在白色处抬笔**。 |
| **点画**（Stippling） | 按色调分布的点（加权 Voronoi 点画）：阴影处密集，亮处稀疏。 | **点数**（Number of dots）、**点大小**（Dot size）；种类：点、按色调变化的圆、短线或三角形。 |
| **一笔画（TSP）**（One line (TSP)） | 将点画的点连成一条不自相交的线，绘制时无需抬笔。 | **点数**（最多 15 000）。 |
| **三角形和单元**（Triangles and cells） | 在按色调分布的点上生成三角网（Delaunay），或点周围的单元（Voronoi）。 | **点数**；种类：三角形或单元。 |
| **线稿**（Line art） | 仅以线条表现图片的边缘。 | **最小细节**（Smallest detail）、**边缘灵敏度**（Edge sensitivity）、**最短线条**（Shortest line）；种类：边缘，或边缘加暗区。 |
| **流线**（Flow lines） | 顺着形状流动的长线，越暗越密。 | **最小间距**（Smallest gap）（最暗处）、**最大间距**（Largest gap）（最亮处）、**曲线大小**（Size of the curves）、**角度**；种类：沿形状或随机流场。 |
| **素描**（Sketch） | 许多短直笔画，落在图片最暗的地方，就像铅笔素描。 | **笔画长度**、**笔画数**（Number of strokes）、**单笔墨量**（Ink of one stroke）（一笔吸收多少暗度）；种类：独立笔画或成链的笔画。 |
| **涂鸦**（Scribble） | 一条游走的环形线，把暗部涂满。 | **环大小**（Loop size）、**线条长度**（Length of the line）（米）、**单遍墨量**（Ink of one pass）。 |
| **V 雕**（V-carve） | 按角度排列的线条，每条线的宽度随其经过处图片的暗度而变：亮处细，阴影处宽，就像 V 形刀切得越深越宽。每条线被切成若干段，每段的亮度决定其宽度；每条线是一个封闭轮廓。变体：**平滑**（Smooth）（通过各段的平滑曲线）或 **棱角**（Angular）（各段之间为直线）。 | **线条宽度**（Width of the lines）（也是最宽线条）、**分段长度**（Length of the pieces）、**最细线条**（Thinnest line）（白色处所占宽度的比例；0：该处没有线条）、**角度**。 |
| **几何多边形**（Geometric polygons） | 将图片的暗色形状分割成多边形（三角形和四边形），图片有边缘的地方多边形更多，多边形之间以及轮廓周围留有间隙：一幅几何（低多边形）图片，可作为墙面装饰或模板。轮廓随形状走，多边形被裁切到轮廓内。也可通过 **排列 → 几何多边形…**（Arrange → Geometric polygons…）使用。变体：**三角形和四边形**（Triangles and quadrangles）、**三角形**（Triangles）；换一个 **种子**（seed）会得到不同的多边形；色调设置（黑点）决定哪部分是暗色形状。 | **多边形间隙**（Gap between the polygons）（0：每条边一条线）、**多边形数量**（Number of polygons）、**跟随边缘**（Follow the edges）（0：均匀，1：仅按边缘）。 |

## 须知

* 设置以图片的毫米为单位，因此更大的图片会得到更多的线条，而不是更粗的线条。请保持线条间距大于笔、激光光斑或刀具的宽度。
* 点是一个小的封闭圆，因此它像其他线条一样被绘制、烧蚀或雕刻。
* **一笔画（TSP）**、**螺旋** 和 **希尔伯特曲线** 以一次长移动绘制；其他风格会按使线条之间移动尽量短的顺序排列。
* 非常精细的设置会产生大量的点：按钮下方的一行文字会在绘制将变慢时发出警告，结果最多为两百万个点。
* 当风格需要更高的对比度时，请先调整图片（**排列 → 调整图像…**（Arrange → Adjust image…）：亮度、对比度、色阶）。

## 图片风格面板

当选中一张图片时，侧面板会有一个 **图片风格**（Picture styles）标签页（选中图片时自动打开，没有选中图片时消失）。顶部有一个与面板同宽的橙色按钮，用于打开 **编辑图像…**（Edit image…）（照片编辑器），其下方的一个按钮打开 **描摹图像…**（Trace image…）；再往下，像图库一样列出每种风格的小图（用该风格绘制的一个三角形）。单击其中一个会打开已选好该风格的 **风格描摹**（Style trace）。
