# 设计工具

PenCreator 使用与 LightCreator 和 MillCreator 相同的工具（baseCreator）编辑形状。工具的快捷键见[键盘快捷键](Keyboard-Shortcuts-ZH)，菜单见[菜单](Menus-ZH)。

## 文本

选择 **文本 (T)**（Text (T)）并在页面上单击：会出现一段文本，**属性**（Properties）标签页随之打开，其中有输入框。你可以在那里设置字体、大小、粗体和斜体、字距和行距以及对齐方式。**转换为曲线**（Convert to curves）会把文本变成可以编辑节点的形状。新文本会采用最近一次修改的文本的设置。

## 编辑

* 在形状上按 **鼠标右键** 会打开其菜单：**复制**（Copy）、**粘贴**（Paste）、**再制**（Duplicate）、**删除**（Delete）、**全选**（Select all）、**编组**（Group）、**取消编组**（Ungroup）、**锁定**（Lock）、**解锁**（Unlock）、翻转和四分之一旋转、子菜单 **排列**（Arrange）（顺序、对齐、居中、**编辑节点**（Edit nodes）、**转换为路径**（Convert to path））和子菜单 **形状运算**（Shape operations）（**并集**（Union）、**交集**（Intersection）、**减去**（Subtract）、**异或**（Exclusive or）、**偏移形状…**（Offset shape…）、**圆角…**（Round corners…）、**转换为曲线**（Convert to curves）；它们也在 **排列** 菜单中）；对于图片还有 **调整图像…**（Adjust image…）和 **描摹图像…**（Trace image…）。不适用于当前选择的项会显示为灰色。
* **按两次 Esc**（半秒内第二次按 Esc）会回到 **选择 (V)**（Select (V)）工具。
* 工作区下方的 **图层行**：64 个图层每个都有一个色块（圆点标出有形状的图层）；单击会把选中的形状放到该图层，双击会打开其设置。参见[图层与笔](Layers-and-Pens-ZH)。

## 导入

* **DXF：** **文件 → 导入 → 导入 DXF…**（File → Import → Import DXF…）（或 **文件 → 打开…**（File → Open…），或拖放）读取 ASCII `.dxf`（R12 及更新版本）：直线、带凸度的多段线、圆弧、圆、椭圆、样条曲线和块均作为轮廓读取，单位为毫米（会读取文件的单位），圆弧和圆作为曲线；相接的线条合并为一条路径。DXF 的图层依次放到项目中尚无形状的图层上。不是线条的内容会被跳过，并在状态行中列出。**排列 → 自动连接路径…**（Arrange → Auto-join paths…）/ **按容差闭合路径…**（Close path with tolerance…）可修补没有完全闭合的路径，**文件 → 导出 → 将所选导出为 SVG…**（File → Export → Export selection as SVG…）/ **将所选导出为 DXF…**（Export selection as DXF…）可将形状写出。
* **LightBurn、MillMage 和 UGS Designer：** **文件 → 导入 → 导入 LightBurn / MillMage 项目…**（File → Import → Import LightBurn / MillMage project…）（`.lbrn2`、`.lbrn`、`.mage`）和 **导入 UGS 设计…**（Import UGS design…）（`.ugsd`）会把形状添加到绘图中。UGS 设计的加工方式会设置尚无形状的图层（挖槽或填充变为 **用线条填充**（Fill with lines），其他的变为 **轮廓**（Outline））。
* **其他程序的文件，双向支持：** DXF（当前格式和 R12，*legacy*）、Illustrator（也包括旧的 PostScript 格式）、带图片的 SVG，以及 LightBurn（`.lbrn2`、`.lbrn`）和 MillMage（`.mage`）项目都可以读取，并按相同格式写回。**文件 → 导出**（File → Export）可将它们写回：**导出 DXF…**（Export DXF…）（当前格式）、**导出 DXF R12（legacy）…**（Export DXF R12 (legacy)…）、**导出 Adobe Illustrator…**（Export Adobe Illustrator…）、**导出 LightBurn 项目…**（Export LightBurn project…）（`.lbrn2`，或者在你这样命名文件时为 `.lbrn`）和 **导出 MillMage 项目…**（Export MillMage project…），此外还有 **导出 SVG…**（Export SVG…）。曲线会被保留（DXF 会将其展平到 0.01 mm）；图片会写入 SVG、LightBurn 和 MillMage 文件，在 DXF 和 Illustrator 文件中则被省略（程序会告诉你省略了多少）。
* **图片（位图）：** **文件 → 导入 → 导入图像…**（File → Import → Import image…）（或将 PNG、JPG、BMP、GIF 或 WebP 文件拖到窗口上）会打开导入对话框：旋转、翻转、亮度、对比度、伽马、自动色阶、负片和尺寸。**调整图像…**（Adjust image…）（位于 **属性** 标签页的 *图像*（Image）部分，或 **排列 → 调整图像…**）可修改页面上的图片，**描摹图像…**（Trace image…）（同一部分，或 **排列 → 描摹图像…**）会把图片的暗区（或亮区）变成轮廓（阈值、斑点过滤、简化、曲线平滑），这些轮廓像其他形状一样被绘制。**排列 → 风格描摹…**（Arrange → Style trace…）会把图片重新绘制为 21 种风格之一的线条（波浪线、螺旋、点画、排线、流线、一笔画…）：参见[风格描摹](Style-Trace-ZH)。
* **编辑图像…**（Edit image…）（**排列** 菜单、右键菜单，或 **图片风格**（Picture styles）标签页中的橙色按钮）会打开所选图片的照片编辑器：**画笔**（brush）、**橡皮擦**（eraser）（涂白色）、**仿制图章**（clone stamp）（Ctrl+单击，Mac 上为 Cmd+单击，指定复制来源，然后涂抹）以及对单击处周围相近灰度区域的 **填充**（fill），仅限灰度，可设置大小、硬度、不透明度和容差，支持撤销和重做。滚轮缩放，右键或中键移动图片；只有在 **应用**（Apply）后绘图才会改变。
* **转换为图像…**（Convert to image…）（选中形状且其中没有图片）会把它们变成一张图片：预览、分辨率（DPI）、尺寸、填充封闭形状以及线宽。**之后删除对象**（Delete the objects afterwards）会删除这些形状；**隐藏对象**（Hide the objects）仅在预览中省略它们的轮廓。
* **描摹图像**（Trace image）和 **风格描摹**（Style trace）窗口中的 **隐藏图片**（Hide the picture）会在预览中只显示结果。
* **用线条绘制的图片：** 放到图层上的图片会将该图层切换为 **图片**（Picture）绘制方式（一次；你可以再改回来），之后图片本身会按该图层的 **图片方法**（Picture method）用线条绘制：**抖动行**（Dithered rows）、**点**（Dots）或 **按色调排线**（Hatching by tone）。在其他绘制方式的图层上，图片只会显示，不会绘制。参见[图层与笔](Layers-and-Pens-ZH#绘制方式)。

## 排列、复制和生成

**插入**（Insert）菜单包含左侧工具栏中用于插入对象的工具（**矩形 (R)**（Rectangle (R)）、**椭圆 (E)**（Ellipse (E)）、**三角形 (Y)**（Triangle (Y)）、**星形 (S)**（Star (S)）、**多边形 (G)**（Polygon (G)）、**心形 (K)**（Heart (K)）、**螺旋 (I)**（Spiral (I)）、**直线 (L)**（Line (L)）、**折线 / 钢笔 (P)**（Polyline / pen (P)）和 **文本 (T)**；正在使用的工具带勾号），然后是 **生成形状…**（Generate shape…）（插件的生成器）和 **在线剪贴画…**（Online clipart…）。

**排列** 菜单中的命令（在 LightCreator、MillCreator 和 PenCreator 中相同）：

* **自动连接路径…**（Auto-join paths…）连接端点距离小于容差的开放路径；**按容差闭合路径…**（Close path with tolerance…）闭合两个端点距离在此范围内的路径。**狗骨 / T 骨转角…**（Dogbone / T-bone corners…）在每个尖角处添加一个缺口，使圆形铣刀能够到达（用于铣削）。
* **网格阵列…**（Grid array…）按行和列复制所选内容。**环形阵列…**（Circular array…）在 *总角度*（Total angle）范围内围绕所选内容的中心放置副本（360° 为一整圈），副本可随位置旋转，也可只移动。最多生成 2000 个副本。
* **沿路径复制…**（Copy along path…）：先选择形状，**最后** 选择路径；每隔 *距离*（Distance）沿路径放置一个副本，副本可以随路径旋转。**路径文本…**（Text on path…）：先选择文本，最后选择路径；文本的轮廓从 *起点*（Start）开始沿路径弯曲（之后它们是轮廓，而不是文本）。
* **按形状修剪…**（Trim by shape…）：先选择线条，**最后** 选择一个封闭形状；保留其内部（或外部）的部分，在线条与其轮廓相交处切断。**删除重复**（Remove duplicates）删除同一图层上轮廓相同的形状（所选内容或整个绘图）。**拆分**（Break apart）把每个轮廓变成一个形状。**简化…**（Simplify…）删除距线条在 *容差*（Tolerance）以内的点。
* **序列文本…**（Serial text…）：选择一段文本；它会按网格复制，其中的 `{n}` 递增，或者使用 **读取 CSV 文件…**（Read a CSV file…）为每一行复制一次，`{1}`、`{2}`… 对应各列。**条形码 / 二维码…**（Barcode / QR code…）在当前图层上以轮廓形式放置二维码或 Code 39 条形码（请做得足够大，以便笔能画出）。
* **嵌套排料…**（Nest shapes…）把所选形状排布在从页面角落开始的 *区域宽度*（Area width）× *区域高度*（Area height）区域内，形状之间保持 *距离*（Distance）。启用 **按实际轮廓**（By the real outlines）（默认开启）时按真实形状排布：小零件可以放进大零件的孔里，L 形可以放进另一个零件的角落，一个编组作为一个零件，**旋转**（Turning）允许零件以半圈、四分之一圈或八分之一圈旋转。**放不下的放到新纸张上**（What does not fit goes on new sheets）会把剩余部分放到新纸张上：每张纸都是一个具有相同图层和材料的新标签页（保存后在这一张之后运行）；不启用时，放不下的形状留在原处。关闭该选项时，形状按其外框逐行排布（*允许旋转*（Allow turning）会把高的形状横放）。**测量…**（Measure…）显示所选内容的尺寸、位置、面积和长度，对于两个形状还会显示它们之间的距离。

**文件 → 导出 → 将所选导出为 SVG…** / **将所选导出为 DXF…** 写出所选形状（没有选中任何内容时写出全部）。

## 摄像头叠加（视图菜单）和描摹对话框

**视图 → 叠加来源…**（View → Overlay from…）把照片、平面图或扫描件放在 **绘图下方**（**加载图片…**（Load picture…）），或者放置设备摄像头的实时画面（**启动摄像头**（Start camera）、**冻结画面**（Freeze frame）；摄像头标签页上的 **叠加**（Overlay）按钮也可以）。勾选 **对齐：在工作区上拖动四个角**（Align: drag the four corners on the work area），然后将其四角拖到材料或工作区的角上（图片会按透视变换跟随），或者给出 **参考点**（Reference points），参考点随设备保存。**不透明度**（Opacity）、**显示叠加**（Show overlay）、**重置到工作区**（Reset to work area）、**水平翻转**（Flip H）、**垂直翻转**（Flip V）、**旋转 90°**（Rotate 90°）和 **移除**（Remove）位于同一窗口中，**视图 → 显示摄像头叠加**（View → Show camera overlay）可显示或隐藏它。图片随项目一起保存。在 **描摹图像**（Trace image）对话框中，可以用滚轮或 **放大**（Zoom in）、**缩小**（Zoom out）和 **重置视图**（Reset view）按钮缩放图片，绿色的 **描摹**（Trace）按钮会生成轮廓。

## 侧面板

* 拖动标签页可将其放到其他位置（顺序会被记住，也会存入备份）。标签页左侧的小箭头可隐藏面板；会保留一条显示标签页名称的窄条，单击某个名称会打开面板并定位到该标签页。
* 标签页：**属性**（Properties）、**图层**（Layers）、**设备**（Device）、**控制**（Control）、**控制台**（Console）、**剪贴画**（Clipart）、**描述**（Description）、**摄像头**（Camera）（当设备有已启用的摄像头时），以及每个有设置的插件各自的标签页。

## 标签页与窗格

分步说明：[窗格与标签页](Panes-and-Tabs-ZH)。

每个打开的绘图、**预览**（Preview）、项目的 G-code 文本（**预览 G-code：name.nc**（Preview G-code: name.nc））、文件的 **G-code 分析**（G-code analysis）以及 **摄像头视图**（Camera view）都是工作区上方的 **标签页**。

* **视图 → 拆分视图：并排**（View → Split view: side by side）或 **拆分视图：上下排列**（Split view: one above the other）将工作区划分为最多 **三个窗格**；**单一视图**（Single view）把所有标签页重新合在一起。每个窗格都有自己的标签栏，带有用于新建绘图的 **+**。
* **拖动标签页** 到另一个窗格（或在其标签栏内拖到其他位置）。也可以使用其菜单（右键）：**移到窗格 N**（Move to pane N）（其他窗格，以及在有空间且该窗格还保留另一个标签页时的新窗格）、**在单独窗口中打开**（Open in a separate window）（适用于预览、G-code 文本和摄像头视图；窗口会记住其位置，**返回主窗口**（Back to the main window）或关闭窗口会将标签页放回）和 **关闭标签页**（Close tab）。在标签页上单击鼠标中键也会关闭它。
* 拖动两个窗格之间的分隔线可改变它们的大小；双击分隔线会使它们等大。
* 关闭窗格中的最后一个标签页会关闭该窗格，其余窗格随之合拢。
* 任何内容都不会打开两次：打开一个已经打开的项目会显示其标签页，一个项目只有一个预览、一个摄像头视图和一个 G-code 文本。
* 有一个绘图是 **当前** 绘图：工具、菜单和快捷键作用于它。其他窗格中的绘图仅供查看，有自己的缩放；单击它会使其成为当前绘图。
* 窗格布局会被记住。

## G-code 文本标签页

**预览 G-code**（Preview G-code）（**保存 G-code**（Save G-code）旁边的按钮）会生成项目的程序（包括已启用的后处理器），并 **以文本形式在标签页中** 显示，带有着色（G 和 M 词、坐标轴、速度、注释），并且可以编辑。标签页中的 **保存 G-code** 将其写入文件；**重新生成**（Make again）从项目重新生成（有修改时会先询问 **放弃修改？**（Lose the edits?））；**分析**（Analyse）在 **G-code 分析** 标签页中显示其刀具路径。有修改的标签页会显示 *已手动修改*（Changed by hand）和一个圆点，关闭时会询问是否保存。没有修改时，项目保存、注释改变、设备设置改变或后处理器改变之后，文本会自动重新生成。**设置 → 视图选项… → 保存后预览 G-code**（Settings → View options… → Preview G-code after saving）（默认关闭）会在每次 **保存 G-code** 后在分析中打开保存的文件。

**行号和阶段（Stages）：** 左侧显示行号（仅在屏幕上显示，绝不写入文件），每个形状在其第一行旁边显示名称（**形状 1**、**形状 2**…）。右侧的 **阶段** 列表为开始、A 面和 B 面、每个图层、元素和形状、每次停止（M0）以及作业结束各提供一个小框：单击即可将其所在行移到文本顶部。视图中第一行所属的阶段会高亮显示。

**折叠、单个形状预览、颜色和字体：** 在块（面、元素、图层、遍、形状、形状的遍）开始的行号旁单击箭头，可将该块折叠到这一行，旁边显示隐藏的行数；单击那里即可重新展开。在列表中的阶段上单击右键可折叠或展开它，**预览** 会打开一个窗口，只显示该形状在整个作业材料上的样子，仿佛只加工它一个，并显示其切割长度和时间。编辑器使用配色方案的颜色；字体（Noto Sans Mono、JetBrains Mono、IBM Plex Mono、Fira Mono）和字号在 **设置 → 程序选项 → G-code 编辑器** 中设置，所有程序通用。
* **在设计中找到形状、保存与取消：** 当 G-code 标签页位于设计旁边（分屏视图）时，在阶段列表中单击一个形状，会选中生成它的对象并将其移到工作区中央；若它在另一面上，会先显示那一面。形状按位置查找：单击文字中的一个字母会选中整段文字。在 **设置 → 程序选项** 中，字体和字号在保存或关闭窗口时生效；窗口底部的 **取消** 会恢复打开窗口时的选项。

## 视图选项

**设置 → 视图选项…**（Settings → View options…）包括主网格和次网格、工作区及其周围空间的颜色、线条粗细，以及：

* **显示图层名称**（Show layer names）（默认关闭）：工作区下方的图层行会在有形状的图层颜色旁写出其名称（长名称会被截断，完整名称在提示中；行满时可横向滚动）。
* **保存后预览 G-code**（Preview G-code after saving）（默认关闭）：见上文。
* **显示变量名**（Show variable names）（默认关闭）：在每个有自定义 G-code 变量的字段标签旁，以斜体加括号显示变量名，例如设备名称旁的 *(machine_name)* 或图层名称旁的 *(layer_name)*；单击会将 `{machine_name}` 复制到剪贴板，可直接粘贴到自定义 G-code 框中（参见[机器控制](Machine-Control-ZH#运行作业)）。

## 图层预设

图层设置上方的 **保存预设…**（Save preset…）和 **加载预设**（Load preset）会打开 **图层预设**（Layer presets）窗口：图层的笔设置以某个名称保存，之后可以应用到任何图层。参见[图层与笔](Layers-and-Pens-ZH#图层预设)。

## 标尺、选择和节点栏

* **标尺 (M)**（Ruler (M)）：工具栏中位于 **缩小 (X)**（Zoom out (X)）之后的工具。从一点拖到另一点，或单击两个点：绘图上方的一条线会显示长度、ΔX、ΔY 和角度，使用程序的单位。靠近形状节点的点会取该节点本身（否则在启用吸附时取网格）。单击形状的直线段（矩形的一条边、一条直线）会测量该线段。测量结果保留到下一次测量、按 **Esc** 或切换到其他工具为止；绘图中的任何内容都不会改变。
* **使用工具时右键单击**（形状工具、钢笔、节点工具、标尺…）相当于按两次 **Esc**：回到 **选择 (V)** 且不选中任何内容；正在用钢笔绘制的线会先完成。使用选择工具时，右键单击仍和以前一样打开上下文菜单。
* **选中多个对象时：** 除了整个选择的边框外，每个对象还有自己的细虚线边框。
* **节点栏** 在名称后显示快捷键：**尖角 (C)**（Corner (C)）、**转为直线 (L)**（To line (L)）、**转为曲线 (S)**（To curve (S)）、**添加节点 (I)**（Add node (I)）、**删除节点 (D)**（Delete node (D)）、**圆角 (R)**（Round (R)）、**断开 (B)**（Break (B)）。**打开 / 闭合**（Open / close）已移除：**断开 (B)** 可打开路径，将路径的一端拖到另一端上即可闭合路径。
* **不输出的图层**（其输出已关闭）会将其对象显示为向工作区颜色淡化。

## 预览：按钮和尺寸

* 预览栏中的选项是 **按钮**：开启时为浅蓝色（与摄像头视图的按钮一样），单击可开启或关闭。
* **尺寸**（Dimensions）像工程图那样显示作业的尺寸：整体的宽度和高度、每个部分的宽度和高度（有多个部分时），以及当零点在画面中时，整体距机器零点的距离。

* **图片：** 也可读取 TIFF（`.tif`、`.tiff`），与 PNG、JPEG、BMP、GIF 和 WebP 一样。

## 工作区上的尺寸、标尺和节点菜单

* **尺寸**（Dimensions）（工作区上方栏中 **刀具路径**（Toolpaths）旁边的按钮）像工程图那样显示绘图：整体以及每个轮廓的宽度和高度（形状的外轮廓和孔各自单独标注），以及圆形轮廓的直径，相同的只标注一次（**4 × Ø 6**）。它不会改变绘图中的任何内容。
* **标尺 (M)** 会吸附形状的节点（用方块标记）、线段的中点（菱形）或圆和椭圆的圆心（圆形）。单击圆会显示从圆心到单击点的半径以及直径；单击椭圆会显示两个半径以及到该点的半径；单击曲线会显示其长度，当曲线是圆弧时，还会显示从圆心到单击点的半径及其长度。
* **节点编辑**（Node edit）：在节点或线段上右键单击会打开节点栏的菜单；**平滑**（Smooth）的快捷键是 **G**，**圆角 (R)** 的半径显示在其按钮之后。

## 单位

* **设置 → 程序选项… → 单位**（Settings → Program options… → Units）选择程序显示长度所用的单位：毫米、厘米、米、英寸或英尺，或者 **与设备相同**（As the device）。它们用于 **属性** 中的尺寸、标尺、绘图上方和预览中的 **尺寸**，以及工程图。
* **设备的单位**（毫米或英寸，在设备窗口中设置）是机器的单位：G-code 以这些单位写出。英寸单位的设备会得到 **G20**，所有长度和进给都以英寸表示；毫米单位的设备得到 **G21** 和毫米。请确认它们是控制器所使用的单位。
* 当设备使用的单位制与程序不同（英寸与毫米）时，尺寸和标尺会同时显示两者：先是程序的单位，机器的单位在方括号中，例如 **25.4 mm [1.000"]**。

## 拖刀

绘图仪可以用 **拖刀** 代替笔进行切割（乙烯基膜、纸、卡纸、模板）：在设备窗口的 **笔**（Pen）页面中，勾选 **工具是拖刀**（The tool is a drag knife）。

* **刀具：** **刀具库** 中的刀具会一次性设置 **刀尖偏移**（offset of the tip）（刀片尖端落后于其轴线的距离）、转角和过切；现成的刀具有 30°、45° 和 60° 刀片（0.15、0.25、0.5 mm）以及装在 CNC 机床刀柄中的拖刀。刀片制造商会给出准确的偏移值。**刀具库…**（Knife library…）（也在 **绘图仪 → 刀具库…**（Plotter → Knife library…）中）会打开刀具库：现成的刀具不能修改，但 **复制**（Copy）可以生成一把你自己的刀具，带有名称、数值和备注，与程序设置一起保存（也包含在其备份中）。设备上的数值属于设备自己：刀具库中的更改不会改变之前已采用该刀具的设备。
* 程序会补偿偏移：轴线走在刀尖之前，在比 **转角大于此值时绕行**（Turn round corners sharper than）（默认 15°）更尖锐的转角处，它会沿一段小圆弧绕过转角，使刀片原地转向、转角保持锐利。每次切割开始时，刀片都会从上一次切割后的朝向转过来，封闭轮廓会越过起点再切 **越过起点继续切割**（Cut on past the start）（0.5 mm）的距离，使其闭合。
* 孔先于其周围的零件切割，这样零件在被切下之前一直被固定。刀具只切割轮廓：填充和图片会被省略（预览中会提示），小于约四倍偏移的轮廓切出来会变圆（有警告）。
* **切割机自行补偿偏移**（The cutter makes good the offset itself）：大多数乙烯基切割机（HPGL）在控制器中完成补偿；勾选后，轮廓按绘制的样子切割。
* 刀片像笔一样下落和抬起：使用 Z 轴时，**落笔** 就是切割深度。
* 预览以灰色绘制轴线的路径，并以图层颜色绘制刀尖实际切出的线。

尚未在真正的切割机上试用：请先在废料上试切。完整说明，包括刀具库和切割机的 HPGL 命令：[拖刀](Drag-Knife-ZH)。
