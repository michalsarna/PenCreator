# 키보드 단축키

Mac에서는 Ctrl이 Cmd입니다. 단축키는 편집기에서 작동하며(시작 화면에서는 작동하지 않음), 텍스트 필드가 키보드 입력을 받는 동안에는 어떤 단축키도 가로채지 않습니다. 필드, **설명**(Description) 탭, G-code 텍스트 탭에 입력하면 글자가 입력됩니다. Mac에서는 시스템 메뉴 바가 모든 단축키를 보여 주지는 않습니다. [macOS에서](#macos에서)를 참조하십시오.

## 메뉴 단축키

이 단축키는 메뉴 항목 옆에 표시됩니다([메뉴](Menus-KO) 참조). 창의 메뉴 바에서는 메뉴가 닫혀 있어도 작동하며, 그 순간 회색인 항목은 아무 일도 하지 않습니다.

| 단축키 | 명령 |
|---|---|
| Ctrl+N | **파일 → 새로 만들기**(File → New) |
| Ctrl+O | **파일 → 열기…**(File → Open…) |
| Ctrl+S | **파일 → 저장**(File → Save) |
| Ctrl+Shift+S | **파일 → 다른 이름으로 저장…**(File → Save as…) |
| Ctrl+Q | **파일 → 종료**(File → Quit) |
| Ctrl+Z | **편집 → 실행 취소**(Edit → Undo) |
| Ctrl+Y 또는 Ctrl+Shift+Z | **편집 → 다시 실행**(Edit → Redo) |
| Ctrl+C | **편집 → 복사**(Edit → Copy) |
| Ctrl+V | **편집 → 붙여넣기**(Edit → Paste) |
| Ctrl+D | **편집 → 복제**(Edit → Duplicate) |
| Delete 또는 Backspace | **편집 → 삭제**(Edit → Delete)(**노드 편집 (N)**(Node edit (N)) 도구에서 노드를 선택한 경우: 노드를 삭제) |
| Ctrl+A | **편집 → 모두 선택**(Edit → Select all) |
| Ctrl+G | **정렬 → 그룹**(Arrange → Group) |
| Ctrl+Shift+G | **정렬 → 그룹 해제**(Arrange → Ungroup) |
| Ctrl+L | **정렬 → 잠금**(Arrange → Lock) |
| Ctrl+Shift+L | **정렬 → 잠금 해제**(Arrange → Unlock) |
| N | **정렬 → 노드 편집**(Arrange → Edit nodes)(**노드 편집 (N)** 도구) |
| Ctrl++ (Ctrl+=) | **보기 → 확대**(View → Zoom in) |
| Ctrl+- | **보기 → 축소**(View → Zoom out) |
| Ctrl+Shift+0 | **보기 → 작업대를 창에 맞추기**(View → Fit bed to window) |
| Ctrl+Shift+9 | **보기 → 모든 객체 맞추기**(View → Fit all objects) |
| Ctrl+Shift+P | **플로터 → 작업 플롯…**(Plotter → Plot of the job…) |
| Ctrl+E | **플로터 → G-code 내보내기…**(Plotter → Export G-code…) |

메뉴 항목 두 개가 같은 단축키를 쓰는 일은 없습니다. 프로그램의 테스트가 이를 확인합니다.

## 도면 탭

| 단축키 | 기능 |
|---|---|
| Ctrl+1 … Ctrl+9, Ctrl+0 | 1번째 … 9번째 탭의 도면을 보여 주며, Ctrl+0은 10번째(도면은 최대 10개까지 열림). |
| Ctrl+W | 표시된 도면을 닫습니다. 저장하지 않은 작업이 있으면 먼저 묻습니다(**저장**(Save), **버리기**(Discard), **취소**(Cancel)). |

## 도구

Ctrl 없이 누르는 글자는 왼쪽 팔레트의 도구를 고릅니다(글자는 버튼의 도움말에 있습니다).

| 키 | 도구 | 키 | 도구 |
|---|---|---|---|
| V | **선택 (V)**(Select (V)) | L | **선 (L)**(Line (L)) |
| N | **노드 편집 (N)**(Node edit (N)) | P | **폴리라인 / 펜 (P)**(Polyline / pen (P)) |
| R | **사각형 (R)**(Rectangle (R)) | T | **텍스트 (T)**(Text (T)) |
| E | **타원 (E)**(Ellipse (E)) | H | **이동 (H)**(Pan (H)) |
| Y | **삼각형 (Y)**(Triangle (Y)) | Z | **확대 (Z)**(Zoom in (Z)) |
| S | **별 (S)**(Star (S)) | X | **축소 (X)**(Zoom out (X)) |
| G | **다각형 (G)**(Polygon (G)) | | |
| K | **하트 (K)**(Heart (K)) | M | **자 (M)**(Ruler (M)) |
| I | **나선 (I)**(Spiral (I)) | | |

| 키 | 기능 |
|---|---|
| Esc | 선택을 해제합니다(그리고 그리던 폴리라인도). |
| Esc 두 번(0.5초 안에) | **선택 (V)** 도구로 돌아갑니다. |
| Space(누르고 있기) | 어떤 도구에서든 화면을 이동합니다. 놓으면 원래 도구로 돌아갑니다. |
| 화살표 키 | 선택 항목을 1 mm 옮깁니다. **Shift** + 화살표 = 10 mm(제어 탭의 **키보드**(Keyboard)가 체크되어 있을 때는 제외). |
| G, I | 다각형과 나선: 작은 창에서 변의 수나 회전 수를 정합니다. 마지막으로 그린 도형에도 적용됩니다. |
| Enter | **폴리라인 / 펜 (P)**으로 그리던 폴리라인을 끝냅니다. |

## 마우스와 키

| 동작 | 기능 |
|---|---|
| 작업 영역에서 휠(또는 핀치) | 포인터를 중심으로 확대/축소합니다. |
| 가운데 또는 오른쪽 버튼으로 끌기 | 작업 영역과 그 옆에서 보기를 이동합니다(**이동 (H)**에서는 왼쪽 버튼으로. 움직이지 않은 오른쪽 클릭은 메뉴를 엽니다). |
| Shift+클릭 또는 Ctrl+클릭 | 도형을 선택에 추가하거나 선택에서 뺍니다. |
| 사각형, 타원, 삼각형, 별, 다각형, 하트, 나선을 그리는 중 Shift | 너비와 높이를 같게 유지합니다. |
| 모서리 핸들 끌기 | 비율을 유지합니다. Shift를 누르면 너비와 높이가 자유롭게 바뀝니다. |
| 회전 중 Shift | 15° 단위로 회전합니다. |
| **확대 (Z)** / **축소 (X)**에서 Shift | 반대로 확대/축소합니다. |
| **폴리라인 / 펜 (P)**에서 오른쪽 클릭 또는 더블 클릭 | 폴리라인을 끝냅니다. 첫 점 가까이 클릭하면 닫힙니다. |
| 도형을 오른쪽 클릭 | 도형의 메뉴([디자인 도구](Design-Tools-KO) 참조). |
| 창의 탭을 가운데 클릭 | 탭을 닫습니다. |
| 창 사이의 선을 더블 클릭 | 창의 크기를 같게 합니다. |
| 작업 영역 아래 레이어 줄 위에서 휠 | 줄을 가로로 스크롤합니다. |

**미리 보기**(Preview) 탭에서는 휠로 확대/축소하고, 끌어서 그림을 옮기며, 더블 클릭하면 처음 보기로 돌아갑니다.

## 제어 탭

**제어**(Control) 탭의 **키보드**(Keyboard)를 체크하면(기본값 꺼짐) 화살표 키가 X와 Y를, Page Up / Page Down이 Z를 그곳에서 고른 간격만큼 움직입니다. [기계 제어](Machine-Control-KO)를 참조하십시오.

## macOS에서

메뉴는 macOS의 시스템 메뉴 바에 있습니다. 이 페이지의 모든 단축키가 그곳에서도 작동합니다.

* **Cmd+N**, **Cmd+O**, **Cmd+S**, **Cmd+Shift+S**, **Cmd+Q**(앱 메뉴 **PenCreator** 안)는 시스템 메뉴 바에 속하며, 메뉴 바가 항목 옆에 표시합니다.
* 나머지 메뉴 단축키(**Cmd+E**, **Cmd+Shift+P**, **Cmd+L**, **Cmd+Shift+L**, **Cmd+=** / **Cmd+-**, **Cmd+Shift+0** / **Cmd+Shift+9**, 편집 단축키)는 프로그램이 자기 창에서 직접 받습니다. Windows나 Linux에서와 똑같이 작동하지만 시스템 메뉴 바는 항목 옆에 표시하지 않습니다. 위의 표에 나와 있습니다.
