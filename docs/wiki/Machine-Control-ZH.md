# 机器控制

> 已确认 PenCreator 可正常工作的机器，以及如何添加你的机器：[TESTS_ON_DEVICES.md](https://github.com/michalsarna/PenCreator/blob/main/TESTS_ON_DEVICES.md)。

PenCreator 通过 **设备**（Device）标签页（连接）、**控制**（Control）标签页和 **机器**（Machine）菜单来控制 GRBL 机器。这些功能全部来自 baseCreator，因此 MillCreator、PenCreator 和 LightCreator 的行为相同。PenCreator 已在一台按照 [Drawing Robot](https://www.printables.com/model/137296-drawing-robot-arduino-uno-cnc-shield-grbl)（Arduino UNO、CNC Shield、GRBL）制作的笔式绘图仪上测试过，但并非这里的所有功能都测试过：在固定位置换笔尚未在真实的绘图仪上试用。在新机器上，请在抬笔或不装笔的情况下测试，并把手放在停止按钮旁。入门步骤见[快速入门](Quick-Start-ZH#8-保存-g-code-或开始绘图)。

## 读取机器

在 **机器 → 设备设置…**（Machine → Device settings…）的 **连接**（Connection）页面设置连接（**串口**（Serial port）及 **端口**（Port），或 **网络（TCP，例如 ser2net）**（Network (TCP, e.g. ser2net)）及 **主机**（Host）），然后在 **设备** 标签页上点击 **连接**（Connect）。程序会读取控制器（`$I` 读取固件，`$$` 读取设置，`$G` 读取状态）。在设备设置的 **机器**（Machine）页面中，**读取机器**（Read the machine）显示控制器报告的内容，**将这些值用于设备**（Use these values for the device）会把 X 和 Y 的行程以及移动速度复制到设备中，这样你就不必手动输入。新设备也可以从 **常用纸张尺寸…**（A usual sheet size…）开始（仅作为起点）。

## 控制标签页

* **位置**（Position）：X、Y 和 Z 的工作坐标和机器坐标，以大字显示。**X0 Y0 Z0**（位于各轴左侧）把工具当前所在的位置设为工作零点（`G10 L20`）；单击数字可输入位置。其下方有：**全部归零**（Zero all）、**X 和 Y 归零**（Zero X and Y）、**移到 X0 Y0**（Go to X0 Y0）（先抬到安全高度）和 **Z 到安全高度**（Z to safe height）。**坐标系**（Coordinates）可选择 G54 … G59。
* **移动**（Move）：XY 和 Z 每次单击的距离是可输入的字段；旁边的按钮可把某个值填入其中（XY 0.1 … 100，Z 0.1 … 20；这些值在设备设置的 **点动**（Jogging）页面中设置）。**速度**（Speed）是设备的 XY 和 Z 速度（在此处的更改持续到设备本身更改为止）。
* **点动按钮**（Jog buttons）（大按钮，位于中间）：方向箭头、**Z▲ Z▼**；方块按钮停止移动。单击一次移动一次。使用 **按住移动**（Hold to move）（适用于 **GRBL 1.1 或更新版本**（GRBL 1.1 or newer））时，按住按钮工具就移动，松开即停止。**键盘**（Keyboard）（默认关闭）可用方向键移动 X 和 Y，用 Page Up / Page Down 移动 Z，步长为所选值。
* **抬笔 / 落笔**（Raise the pen / Lower the pen）（位于 Home、Unlock、Pause 和 Resume 下方）：用设备的 Z 轴或舵机，在原地把笔移到 **笔**（Pen）页面设置的 *抬起* 或 *落下* 位置（并等待那里设置的延时）。便于在作业前手动设置笔的高度；作业运行时它们不可用。
* **宏**（Macros）：发送你编写的 G-code 的按钮（设备设置的 **宏** 页面）。方括号中的变量会在发送宏时被替换：`[posx] [posy] [posz]`（工作坐标）、`[mposx]` …、`[xmin] [xmax] [ymin] [ymax]`（作业的外框）、`[safez]`（使用 Z 轴时的抬笔高度，使用舵机时为 5 mm）。宏中不允许使用 `$RST`。同一页面还有在每个作业 **之前** 和 **之后** 运行的 G-code（停止之后也会运行）。

## 运行作业

* **开始**（Start）流式发送整个作业；**从指定行…**（From line…）（也在 *机器* 菜单中）从程序的某一行开始：机器会先被带到程序在该处应有的状态（单位、坐标系、笔、进给、位置），处于安全高度，然后发送其余部分。当无法推算出这些状态时（例如在 `G53` 或 `G92` 之后），它会拒绝执行。
* **检查程序**（Check the program）（*机器* 菜单，或 **点动** 页面上的 *每次运行前检查程序*（Check the program before every run））：控制器以检查模式（`$C`）运行一遍程序。机器不会移动，无法识别的行会连同其行号一起报告。启用该选项时，只有检查没有发现问题，真正的作业才会开始。
* **作业选项**（Job options）（位于 Frame 和 From line… 下方；仅限本次会话，不保存；可组合使用也可单独使用，它们会改变 G-code、预览和估算）：**一次一个元素**（One element at a time）会把每个元素（一个编组，即使跨多个图层，或不属于任何编组的形状）连同其所有图层和所有遍数完整绘制完，再绘制下一个，先从距起始角最近的元素开始（关闭时：一个图层接一个图层）。它适用于使用同一支笔的图层：如果笔不同，每次切换都会换笔（暂停）。**仅所选**（Selection only）只绘制保存 G-code 或开始作业时在工作区上选中的形状；没有选中任何内容就意味着没有内容可绘制。
* **在固定位置换笔：** 在设备设置的 **笔** 页面中，打开 *在固定位置换笔*（Change the pen at a fixed place）并给出位置（X 和 Y，使用工作区坐标；可以位于工作区之外，例如放置笔架或换笔机构的地方）。当下一个图层需要另一支笔时，笔会抬起，绘图仪移动到该位置，发送 *该位置的 G-code*（G-code at the place）（最多 20 行，用于自动换笔的机构），然后在那里停止（`M0`），以便手动或由机构换笔；对于无需等待的机构，可以关闭 *在此停止 (M0)*（Stop there (M0)）。前往该位置的路径会计入预览和估算。不设位置时，作业在原地停止。此功能只在模拟器中试过，尚未在带换笔器的机器上试用。
* **文件的 G-code（设备设置，G-code 页面）：** *文件最开头*（Very start of the file）（位于注释和文件头之前：`%`、程序号、控制器的文件头）和 *文件最末尾*（Very end of the file）（位于 `M30` 之后）；花括号中的词会在生成文件时被替换：`{project_name}`（项目文件名，不含扩展名；保存前为 `untitled`）、`{project_path}`（项目尚未保存时为空）、`{date}` 和 `{time}`（UTC）、`{machine_name}`、绘图在机器坐标中的外框（`{min_x}` `{max_x}` `{min_y}` `{max_y}` `{min_z}` `{max_z}`）及其尺寸（`{width}` `{height}` `{depth}`）；在换笔的 G-code 中还有 `{layer_name}`、`{layer_index}` 和 `{total_layers}`。各框下方的 **可用变量**（Variables you can use）会列出它们，**设置 → 视图选项… → 显示变量名**（Settings → View options… → Show variable names）会在有变量的字段旁显示变量名。未知的名称以红色显示，在修正之前不会生成任何 G-code（没有文件、没有 G-code 文本、没有作业）；状态行会说明原因。**自定义文件格式**（Own file format）是对完成的程序进行的最后一遍处理，用于以自己方式读取 G-code 的控制器；默认全部关闭，此时文件与之前相同：*整数后加小数点*（Decimal point after whole numbers）（`X1` 变为 `X1.`）、*开头和结尾加 %*（% at the start and end）、*暂停指令*（Dwell word）（`G4 P` 以秒为单位、`G4 P` 以毫秒为单位或 `G4 X` 以秒为单位；数值会被换算）、*行号*（Line numbers）（N10、N20、… 带步长）和 *删除注释*（Remove comments）。插件的后处理器也会作用于完成的文件（参见[插件](Plugins-ZH)）。
* **项目注释：** **描述**（Description）标签页的文本会在程序开头的名称之后以 `(Note: …)` 行写入（括号变为 `<` `>`，最多 60 行，每行 100 个字符）。
* **预览：** **绘图仪 → 作业绘图…**（Plotter → Plot of the job…）和 **预览…**（Preview…）按钮会在工作区中绘图旁以标签页形式打开预览。其菜单（在标签页上右键单击）中有 **在单独窗口中打开**（Open in a separate window）；**返回主窗口**（Back to the main window）会把它放回。参见[快速入门](Quick-Start-ZH#5-查看绘图)。
* **暂停：** 当程序执行到换笔处时，机器会在那里停下，并有窗口提示应装上哪支笔。**继续作业**（Continue the job）继续执行，**停止作业**（Stop the job）结束作业。作业等待期间，你可以在控制标签页上点动和归零。
* 作业期间出现的错误和警报会被计数，并记住每种的第一行。

## 机器菜单

* **固件设置 ($$)**（Firmware settings ($$)）：控制器的设置，带搜索和过滤器，可只显示与典型值不同的设置。更改会在确认后写入；之后会重新读取设置。**会话中的第一次更改会把所有设置保存到** 数据文件夹中的文件（`firmware-backups`）。**备份到文件…**（Back up to a file…）和 **从文件恢复…**（Restore from a file…）可手动执行（写入之前会将文件与控制器进行比较，写入后再读回）；**出厂设置 ($RST=$)…**（Factory settings ($RST=$)…）需要输入单词 RESET。
* **校准**（Calibration）：*每毫米步数*（steps per millimetre）（请求一次移动，测量它，得到新的 `$100` / `$101` / `$102` 并写入）和 *各轴的垂直度*（squareness of the axes）（输入一个矩形的两条对角线：会显示角度和偏移）。
* **禁入区**（No-go zones）（设备设置，*禁入区* 页面）：纸张上笔绝不能进入的矩形和圆形区域（夹子、尺子），每个都有开关和名称，在工作区上以红色绘制。抬笔移动会自动绕开已启用的区域，保持 1 mm 距离，走最短的路径；穿过某个区域绘制的线条，或无法绕开的移动（起点或终点在区域内），会成为作业的警告。在形状上右键单击可选择 **添加为禁入区**（Add as no-go zone）：每个形状都会变成一个区域（圆形的为圆，否则为其外接矩形），并从绘图中移除。当设备有禁入区时，侧面板会有一个 **禁入区** 标签页，其中有相同的行。区域和页面与 LightCreator 和 MillCreator 中的相同。
* **旋转附件**（Rotary attachment）（设备设置，*旋转*（Rotary）页面）：用于在杯子、瓶子或蛋上绘制。卡盘或滚轮、工件直径、每圈微步数以及控制器在 Y 轴上需要的每毫米步数（`$101`）；Y 电机转动工件，因此 G-code 保持不变，绘图被缠绕在工件上。启用时，工作区每绕一圈处都有一条蓝线（**周长 …**（Circumference …）），高于此的绘图会成为作业的警告。该页面与 MillCreator 中的相同。
* **诊断与统计**（Diagnostics and statistics）：控制器的输入引脚（限位开关、探针、门、暂停、复位、启动）、固件、此机器的作业、运行时间、警报和错误，以及 **维护提醒**（maintenance reminders）（例如"每 50 小时给导轨上油"；在 **维护**（Maintenance）页面设置）。**导出诊断信息 (zip)…**（Export diagnostics (zip)…）保存报告、设置、控制台内容和程序。

## 控制器设置的副本

每台设备都会保存其控制器设置（`$$`）的副本。第一次连接机器时会创建一份，之后每当连接时读取的设置与最新副本不同时都会再创建一份：状态栏和控制台会说明有多少项设置发生了变化以及是哪些（`$110: 3000 → 5000`），这样你就能注意到从其他程序或由控制器自身所做的更改。在这里所做的更改（在 **固件设置 ($$)** 中写入）会得到自己的副本，但不会发出警报。固件设置窗口中的 **立即创建副本**（Make a copy now），以及设备设置 **机器** 页面中的同名按钮，可手动创建副本；**恢复…**（Restore…）会将副本与控制器进行比较，并在确认后写回差异；**删除**（Delete）会删除一份副本。最多保留最新的八份。副本是设备的一部分，因此包含在 **程序备份** 和导出的设备文件中。

## 控制台

**控制台**（Console）标签页显示发往控制器的内容（`>`）、返回的内容（`<`）以及程序的消息（`#`）。在其字段中键入的 **你自己的命令** 有单独的颜色，以便与程序发送的内容区分开。在该字段中，**向上** 和 **向下** 键会在你从该字段发送过的命令（仅限这些命令）之间切换；你正在输入的内容会在末尾重新出现。该列表保留到程序关闭为止。**设置 → 视图选项… → G-code 控制台**（Settings → View options… → G-code console）可设置字体大小和颜色。

## 警报和错误

**GRBL 版本。** 在设备的 **连接** 页面的 *GRBL 版本*（GRBL version）下选择电路板的版本：**GRBL 1.1 或更新版本**（GRBL 1.1 or newer）（默认；也适用于 grblHAL 和 FluidNC）、**GRBL 1.0**、**GRBL 0.9**、**GRBL 0.8**、**GRBL 0.7 或更早版本**（GRBL 0.7 or older），或 **Smoothieware（非 GRBL）**（Smoothieware (not GRBL)）。GRBL 0.8、0.9 和 1.0 以 `<Idle,MPos:…,WPos:…>` 报告位置，并且没有 `$J=` 点动命令，因此程序用普通的 `G91` / `G1` 移动进行点动；这种点动无法中途取消，会一直走完其步长。GRBL 0.7 完全没有实时命令：没有状态报告（因此没有位置），没有 Pause、Resume、Home 或 Unlock，Stop 只会丢弃尚未发送的行，而电路板会执行完已收到的内容；该固件还会截断超过 49 个字符的行。通过主轴输出（`M3 S…`）抬笔的舵机在所有版本中工作方式相同。

**不使用 G-code 的绘图仪。** 同一列表中还有 **AxiDraw / EggBot（EBB，非 GRBL）**（AxiDraw / EggBot (EBB, not GRBL)）和 **HPGL 绘图仪（非 GRBL）**（HPGL plotter (not GRBL)）。程序仍然生成 G-code；连接层会把每一行转换为绘图仪自己的命令，因此开始、进度、换笔时的停止、暂停和停止都与 GRBL 一样工作。笔是抬起还是落下，根据设备的抬笔设置判断（Z 高度或舵机值，取更接近的那个）。*AxiDraw / EggBot：* 选择 **电机**（Motors）（AxiDraw：两个电机驱动一条皮带；EggBot：每个轴一个电机）、**每毫米步数**（Steps per mm）（AxiDraw 为 80）、以百分比表示的 **抬笔**（Pen up）和 **落笔**（Pen down）高度，以及 **反转**（Reverse）X 或 Y（AxiDraw 的 Y 朝前计数，因此默认反转 Y；请将设备的机器零点设为左后角）。电路板没有限位开关：连接之前，请把笔放在绘图开始的角落，因为那个位置就是零点；**Home** 会开回该处。重新连接会把笔当前所在的位置设为新的零点。电路板以恒定速度移动，没有加速度，因此请从较低的抬笔移动速度开始（例如 1500 mm/min），在绘图仪保持定位准确的情况下再逐步提高。对于 EggBot，请自行设置 **每毫米步数**：80 是 AxiDraw 的值。停止会清空电路板的队列，抬起笔，并读取电机停止的位置。*HPGL：* 选择 **每毫米绘图仪单位**（Plotter units per mm）（大多数为 40）和 **流控制**（Flow control）（RTS/CTS 或 XON/XOFF，与绘图仪上的设置一致），并将设备的机器零点设为左前角（绘图仪会截去负坐标）；绘图仪不做任何应答，因此端口接收了一行就视为该行已完成，停止后绘图仪仍会绘制其缓冲区中的内容。*HPGL 命令：* HPGL 设备在设备窗口中会有一个 **HPGL** 页面（仅此时才有），因为不同的绘图仪和切割机对 HPGL 的理解略有不同。它设置在 **开始时**（At the start）（`IN;SP1;PU;`）、程序 **结束时**（At the end）（`PU;`）、**落笔或落刀**（Pen or knife down）（`PD;`）和 **抬笔或抬刀**（Pen or knife up）（`PU;`）时发送的内容，以及 **速度**（Speed）（`VS{speed};`，单位 cm/s，在绘图速度改变时发送，**最多** 为设备的最高速度；留空：从不发送）和 **压力**（Force）（`FS{force};`，单位克，在开始时发送一次；0：从不发送）。命令以 `;`（或换行）结尾；**恢复常用命令**（Back to the usual commands）会恢复默认值。这些绘图仪没有可读取的设置，没有检查模式（检查程序会被跳过），也没有自己的状态：显示的位置是程序把笔发送到的位置。两者都尚未在真实的绘图仪上试用：请先在抬笔且不放纸的情况下试运行第一个作业。

**LinuxCNC（文件）。** 添加设备时选择 **LinuxCNC（文件）**（LinuxCNC (file)）作为控制器（或在 **连接** 页面上勾选）。LinuxCNC 自己运行程序，因此没有连接：**开始** 会保存 G-code 文件，供你在 LinuxCNC 中打开。笔按设备的抬笔方式抬起和落下（Z 轴、舵机或你自己的 G-code，参见 **笔** 页面）。尚未在真实的机器上试用。

**由你自己的 G-code 抬笔。** 在设备的 **笔** 页面（以及添加设备的窗口）中，**抬笔方式**（The pen is lifted by）除了 Z 轴和舵机之外还有 **自定义 G-code**（Own G-code）：编写 **抬笔** 和 **落笔** 的行（每个最多 10 行，纯 ASCII），例如对主轴输出上的电磁铁使用 `M3 S1000` 和 `M5`，或对 Marlin 的舵机使用 `M280 P0 S…`。每次笔移动时都会写入这些行，随后是设备的等待时间。AxiDraw / EggBot 和 HPGL 绘图仪不读取 G-code，因此不为它们提供此选项。

当 GRBL 报告 `ALARM:n` 或 `error:n` 时，控制台会在其下方加一行解释，状态栏也会显示。这些解释提供程序的全部 38 种语言版本。

> ⚠️ 点动、笔按钮和暂停都会发送真实的移动。请让停止按钮保持在伸手可及之处。

## 机器停止时

警报、作业中的错误或控制器无应答会在 **屏幕中央打开一个窗口**：说明发生了什么，并有两个大按钮：**STOP**（红色：停止作业和主轴）和 **UNLOCK**（橙色：清除警报，`$X`）。解锁之前请先查明停止的原因：工具可能还在材料中。

## 倍率调整和已保存位置

当 GRBL 1.1 或更新版本的控制器报告倍率时，控制标签页上会有 **倍率**（Overrides）：作业运行时，进给可以按 10 % 和 1 % 的步长调整，快速移动可降到 50 % 或 25 %。**已保存位置**（Saved positions）（同样需要 GRBL 1.1 或更新版本）会记住工具所在的位置（**保存此处**（Save here）：机器坐标，带名称），并可回到那里：先将 Z 抬到两个高度中较高的那个，然后移动 X 和 Y，最后将 Z 降到保存的高度。× 会删除一个位置。该列表保存在共享数据文件夹中的 `saved_positions.json`。**Smoothieware（非 GRBL）** 像 GRBL 一样流式发送，尚未在真实的电路板上试用。

## 摄像头：RTSP、照片、视频和延时摄影

* **摄像头** 在设备设置的 **摄像头**（Camera）页面中设置（最多 8 个；使用 **在摄像头标签页中显示**（Shown in the Camera tab）的那个）：**地址**（Address）或 **本机摄像头**（Camera of this computer）（及其 **摄像头编号**（Camera number））、名称、**摄像头旋转**（Camera rotation）以及启用它的勾选框。地址可以是 `http://` 或 `https://`（例如 MJPEG 流）、`rtsp://`、`udp://`、`rtp://` 或 `rtmp://`；其他任何地址都以红色显示。摄像头显示在侧面板的 **摄像头** 标签页中，栏中的 **摄像头视图**（Camera view）按钮会把它作为工作区的标签页打开。
* **摄像头视图** 按钮以三种方式之一打开摄像头的实时画面，通过视图顶部的三个图标选择，并按摄像头分别保存（也可在 **视图 → 视图选项**（View → View options）中设置）：**单独窗口**（Separate window）（一个独立的窗口，带有与主窗口相同的栏，可以移出程序窗口）、**侧边标签页**（Side tab）（侧面板的摄像头标签页）或 **工作区中的标签页**（Tab in the work area）（与绘图并列）。画面可用鼠标滚轮或其左下角的缩放栏缩放（最多 8×），拖动可移动，双击可显示完整画面；缩放和单独窗口的位置随设备保存。画面下方有：**叠加**（Overlay）、照片、视频和延时摄影。该视图在 LightCreator、MillCreator 和 PenCreator 中相同。
* **RTSP 流**（`rtsp://` 或 `rtsps://`，摄像头需要时在地址中包含用户名和密码）可作为摄像头地址使用。流由 **ffmpeg** 解码，ffmpeg 作为单独的程序运行：程序会先在自身旁边查找（安装包自带一个），然后在 macOS 应用的资源中查找，最后在系统的 PATH 中查找。没有它时，摄像头视图会提示。如果流中断，每隔几秒会重新打开。带密码的地址可以在计算机的进程列表中看到：请使用只能查看的摄像头账户。
* **其他流：** `udp://` 和 `rtp://`（来自编码器的 MPEG-TS 或 RTP，也支持组播；`udp://@:5000` 监听一个端口）以及 `rtmp://` 由 ffmpeg 以同样的方式读取。20 秒内没有任何数据的流会被视为已断开并重新打开。安装包自带的精简版 ffmpeg 不支持 TLS 地址（`rtsps://`、`rtmps://`）。
* **摄像头选项**（Camera options）（位于 ffmpeg 读取的流地址下方，默认关闭）：**RTSP 使用 UDP**（Use UDP for RTSP）（仅适用于 `rtsp://` 地址：延迟比 TCP 小，但在网络不佳时画面可能破碎）和 **低延迟**（Low latency）（更快获得最新画面，不缓冲；画面可能卡顿）。更改它们时会重新打开流。
* **视频格式**（Video format）（在摄像头视图中）：**自动**（Automatic）（推荐）会把 IP 摄像头的流原样复制到 **MP4** 文件中。不进行任何解码或重新编码，因此处理器几乎没有负担，画质就是摄像头的画质。副本就是摄像头发送的流：程序的旋转和画面设置不会应用到它上面。逐张发送图片的摄像头（MJPEG 地址、本机摄像头）会被录制为 **AVI**（Motion-JPEG）。**MP4** 要求复制流（不是流的摄像头会被录制为 AVI，按钮下方的一行文字会说明）；**AVI** 始终写入 Motion-JPEG 图片。
* 在录制标签页的摄像头面板上：**拍照**（Take a photo）（JPEG）、**录制视频**（Record video）/ **停止录制**（Stop recording）（按 **视频格式** 生成流的 `.mp4` 副本或 Motion-JPEG `.avi`；AVI 可在常见播放器中播放，帧率为实际帧率）以及 **延时摄影**（Time-lapse）：**每隔**（Every）N 秒，或 **每个图层之后**（After each layer）（在作业的下一个图层开始时和作业结束时各拍一张；需要用 **开始** 从程序向机器发送作业），并有 **开始延时摄影**（Start time-lapse）/ **停止延时摄影**（Stop time-lapse）。
* 侧面板的 **录制**（Recording）标签页为设备的每个摄像头提供一个面板，以摄像头命名。每个摄像头独立录制，其设置与其一起保存：**拍照**、**录制视频**、**延时摄影**（方式及其开始和停止）、**视频格式**、**文件夹**（Folder），以及其 **摄像头视图** 的打开方式。正在录制但不是视图所显示的摄像头会读取自己的画面。有多个摄像头时，文件名中包含摄像头名（`box-Side_camera-photo-0001.jpg`），所有文件都放在同一个文件夹中。摄像头视图的画面下方只有它所显示的摄像头的按钮：照片、视频、延时摄影的开始和停止。
* **移开笔拍照**（**录制** 标签页 → **移开拍摄延时照片**（Time-lapse photos aside）→ **每次拍照时移开机头**（Move the head aside for each photo））：作业期间，每张延时照片都会等到下一次抬笔移动。笔保持抬起，机头移到 **位置**（Place）（机器坐标；在 AxiDraw 或 HPGL 绘图仪上，从绘图仪启动时所在的位置开始计数；**使用当前位置**（Use the current position）取其当前所在位置），程序等待 **拍照前等待**（Wait before the photo）的时间，然后拍下之后到来的一张画面。随后笔返回，作业继续。延时摄影行中的 **每次抬笔后**（After every lift）会在每次抬笔时拍一张照片：绘图会花费长得多的时间。
* **HPGL 绘图仪或切割机** 可以用自己的命令移开：**设备设置 → HPGL → 拍照时的移开路径**（Device settings → HPGL → Way aside for photos）（例如 `PA0,8000;`），在抬笔之后发送；它会通过绝对移动返回。留空：使用录制标签页的 **位置**。HPGL 绘图仪不做任何应答，因此 **拍照前等待** 必须把移开所需的时间也算进去。
* **拆分长线**（Split long lines）（录制标签页）：长直线会被拆成 2 到 256 条较短的线发送，每条至少为所设的长度。这样作业可以更快地停下，进度也更平稳。路径保持不变；空移和圆弧保持完整。
* **文件名** 以项目文件名开头：`name-photo-0001.jpg`、`name-video-0001.mp4` 或 `name-video-0001.avi`；延时摄影有自己的文件夹（`name-timelapse-0001`），其中是 `name-frame-00001.jpg` 或 `name-layer-00001.jpg`。项目保存之前，文件名不含项目部分（`photo-0001.jpg`）。编号接续已有文件的编号。
* **文件夹**：未选择时，文件放到项目文件旁的 `camera` 文件夹中；如果该文件夹已存在，则使用 `camera00`、`camera01`… 中第一个空闲的，本次运行的其余文件都留在其中。尚无文件的项目使用共享数据文件夹中的 `camera` 文件夹。**选择文件夹…**（Choose the folder…）为所有内容设置同一个文件夹（它会为所有程序保存，连同视频格式和延时摄影设置）。摄像头视图关闭或隐藏时，录制仍会继续。

## macOS："No route to host"

macOS 会阻止程序访问本地网络，直到它们获得允许，而新构建或更新后的程序可能需要重新允许。如果网络上的控制器或摄像头无法访问，且消息显示 *No route to host*，请打开 **系统设置 → 隐私与安全性 → 本地网络**（System Settings → Privacy & Security → Local Network），并为该程序打开开关（如果是从终端启动的：为终端打开）。如果已经打开，请先关闭再打开，然后重新启动程序。
