# Design tools

PenCreator edits shapes with the same tools as LightCreator and MillCreator (baseCreator).

* **Right mouse button** on a shape opens the context menu: copy, paste, duplicate, delete, select all, group, ungroup, lock, unlock, flip, turn, the *Arrange* submenu (order, alignment, centring, edit nodes, convert to path) and the *Shape operations* submenu (union, intersection, subtract, exclusive or, offset shape, round corners, convert to curves; they are also in the **Arrange** menu); for a picture also *Adjust image…* and *Trace image…*. The entries that do not fit the selection are grey.
* **Pictures (bitmaps):** **File → Import → Import image…** (or drop a PNG, JPG, BMP, GIF or WebP file on the window) opens the import dialog: rotate, flip, brightness, contrast, gamma, auto levels, negative and size. **Adjust image…** (in the *Image* section of the Properties tab, or **Arrange → Adjust image…**) changes a picture on the page, and **Trace image…** (the same button, or **Arrange → Trace image…**) turns its dark (or light) areas into outlines (threshold, speckle filter, simplification, curve smoothing) that are drawn like any other shape. A picture put on a layer switches that layer to the **Picture** drawing (once; you can change it back), and then the picture itself is drawn with lines, by the **Picture method** of the layer: **Dithered rows** (the picture is dithered and every row is drawn as lines where it is dark), **Dots** (a dot for every dark cell) or **Hatching by tone** (crossed hatching: the darker the picture, the more directions of lines). For the first two you choose the **Dithering** (threshold, Floyd–Steinberg, Jarvis, Stucki, Atkinson, ordered); the **Fill line gap** and **angle** of the layer set the distance and the direction of the rows. On a layer with another drawing a picture is only shown.
* **Side panel:** drag a tab to put it in another place (the order is remembered, also in a backup). The small arrow at the left of the tabs hides the panel; a narrow strip with the names of the tabs stays, and a click on a name opens the panel on that tab.
* **Esc twice** (a second Esc within half a second) goes back to the Select tool.
* **Layer bar** under the editor: one row of 64 colours (a dot marks the layers with shapes); a click puts the selected shapes on that layer, a double click opens its options.
