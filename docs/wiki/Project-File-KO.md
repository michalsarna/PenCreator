# 프로젝트 파일

PenCreator는 **`.cre`**로 저장합니다. LightCreator와 MillCreator도 쓰는 baseCreator의 프로젝트 파일로, 도면, 설명, **프로그램마다 섹션 하나**(`laser`, `mill`, `pen`)가 들어 있는 JSON 파일 하나입니다. 각 프로그램은 자기 섹션을 쓰고 다른 프로그램의 섹션은 건드리지 않으므로, 프로젝트가 아무것도 잃지 않고 프로그램 사이를 오갑니다.

`pen` 섹션에는 64개 레이어(이름, 색, 표시 및 그리기 여부, 그리기 방식, 라이브러리 펜, 펜 너비, 속도, 채우기 간격과 각도, 교차선, 그리는 횟수, 그림 방식과 디더링, 작업 순서상의 위치), **레이어가 사용하는 내 펜**(다른 컴퓨터에서 연 프로젝트가 이를 함께 가져가 그곳의 **내 펜**(My pens)에 추가되도록), 그리고 프로젝트를 만든 플로터에 관한 메모(이름과 용지 크기)가 들어 있습니다. 용지 크기가 다른 장치에서 프로젝트를 열면 상태 줄에 그렇게 표시됩니다. 범위를 벗어난 번호의 레이어는 기본 레이어로 바뀝니다.

설명(**설명**(Description) 탭)은 프로젝트의 일부이며, PenCreator는 이를 G-code에도 `(Note: …)` 줄로 씁니다. 파일이 있는 프로젝트는 변경 후 약 20초 뒤 그 파일에 자동으로 저장됩니다([설정과 파일](Settings-and-Files-KO) 참조). LightCreator나 MillCreator에서 만든 프로젝트는 여기서 도면, 설명, 기본 펜과 함께 열리며, 저장하면 그 프로그램들의 섹션은 원래대로 다시 기록됩니다. 프로그램이 아는 것보다 새로운 컨테이너 형식(또는 새로운 `pen` 섹션)의 파일은 메시지와 함께 거부됩니다.
