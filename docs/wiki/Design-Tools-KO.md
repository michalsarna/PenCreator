# 디자인 도구

PenCreator는 LightCreator, MillCreator와 같은 도구(baseCreator)로 도형을 편집합니다. 도구의 단축키는 [키보드 단축키](Keyboard-Shortcuts-KO)에, 메뉴는 [메뉴](Menus-KO)에 있습니다.

## 텍스트

**텍스트 (T)**(Text (T))를 고르고 페이지를 클릭합니다. 텍스트가 나타나고 입력 필드가 있는 **속성**(Properties) 탭이 열립니다. 그곳에서 글꼴, 크기, 굵게와 기울임, 글자 간격과 줄 간격, 정렬을 설정합니다. **곡선으로 변환**(Convert to curves)은 텍스트를 노드를 편집할 수 있는 도형으로 바꿉니다. 새 텍스트는 마지막으로 바꾼 텍스트의 설정을 이어받습니다.

## 편집

* 도형 위에서 **마우스 오른쪽 버튼**을 누르면 메뉴가 열립니다: **복사**(Copy), **붙여넣기**(Paste), **복제**(Duplicate), **삭제**(Delete), **모두 선택**(Select all), **그룹**(Group), **그룹 해제**(Ungroup), **잠금**(Lock), **잠금 해제**(Unlock), 뒤집기와 90° 회전, 하위 메뉴 **정렬**(Arrange)(순서, 맞춤, 가운데 배치, **노드 편집**(Edit nodes), **패스로 변환**(Convert to path)), 하위 메뉴 **도형 연산**(Shape operations)(**합치기**(Union), **교차**(Intersection), **빼기**(Subtract), **배타적 합**(Exclusive or), **도형 오프셋…**(Offset shape…), **모서리 둥글게…**(Round corners…), **곡선으로 변환**(Convert to curves). 이것들은 **정렬** 메뉴에도 있습니다), 그림이면 **이미지 조정…**(Adjust image…)과 **이미지 트레이스…**(Trace image…)도 있습니다. 선택 항목에 맞지 않는 항목은 회색입니다.
* **Esc 두 번**(0.5초 안에 두 번째 Esc)은 **선택 (V)**(Select (V)) 도구로 돌아갑니다.
* 작업 영역 아래의 **레이어 줄**: 64개 레이어마다 견본이 하나씩 있습니다(점은 도형이 있는 레이어를 표시). 클릭하면 선택한 도형을 그 레이어에 놓고, 더블 클릭하면 그 설정을 엽니다. [레이어와 펜](Layers-and-Pens-KO)을 참조하십시오.

## 가져오기

* **DXF:** **파일 → 가져오기 → DXF 가져오기…**(File → Import → Import DXF…)(또는 **파일 → 열기…**(File → Open…), 또는 끌어 놓기)는 ASCII `.dxf`(R12 이상)를 읽습니다. 선, 볼록(bulge)이 있는 폴리라인, 호, 원, 타원, 스플라인, 블록을 윤곽선으로, 밀리미터 단위로(파일의 단위를 읽음) 가져오며, 호와 원은 곡선으로 가져옵니다. 서로 맞닿은 선은 하나의 패스가 됩니다. DXF의 레이어는 아직 도형이 없는 프로젝트 레이어로 차례로 들어갑니다. 선이 아닌 것은 빠지며 상태 줄에 그 이름이 표시됩니다. **정렬 → 패스 자동 연결…**(Arrange → Auto-join paths…) / **허용 오차로 패스 닫기…**(Close path with tolerance…)는 완전히 닫히지 않은 패스를 고치고, **파일 → 내보내기 → 선택 영역을 SVG로 내보내기…**(File → Export → Export selection as SVG…) / **선택 영역을 DXF로 내보내기…**(Export selection as DXF…)는 도형을 다시 파일로 씁니다.
* **LightBurn, MillMage, UGS Designer:** **파일 → 가져오기 → LightBurn / MillMage 프로젝트 가져오기…**(File → Import → Import LightBurn / MillMage project…)(`.lbrn2`, `.lbrn`, `.mage`)와 **UGS 디자인 가져오기…**(Import UGS design…)(`.ugsd`)는 도형을 도면에 추가합니다. UGS 디자인의 절삭 방식은 아직 도형이 없는 레이어를 준비합니다(포켓이나 채우기는 **선으로 채우기**(Fill with lines), 나머지는 **윤곽선**(Outline)이 됩니다).
* **다른 프로그램의 파일, 양방향:** DXF(현재 형식과 R12, *legacy*), Illustrator(옛 PostScript 형식 포함), 그림이 들어 있는 SVG, LightBurn(`.lbrn2`, `.lbrn`) 및 MillMage(`.mage`) 프로젝트를 읽고, 같은 형식으로 다시 씁니다. **파일 → 내보내기**(File → Export)가 다시 씁니다: **SVG 내보내기…**(Export SVG…) 외에 **DXF 내보내기…**(Export DXF…)(현재 형식), **DXF R12 내보내기 (legacy)…**(Export DXF R12 (legacy)…), **Adobe Illustrator 내보내기…**(Export Adobe Illustrator…), **LightBurn 프로젝트 내보내기…**(Export LightBurn project…)(`.lbrn2`, 또는 파일 이름을 그렇게 지으면 `.lbrn`), **MillMage 프로젝트 내보내기…**(Export MillMage project…). 곡선은 유지됩니다(DXF는 0.01 mm로 평탄화합니다). 그림은 SVG, LightBurn, MillMage 파일에는 들어가고 DXF와 Illustrator 파일에서는 빠집니다(프로그램이 몇 개인지 알려 줍니다).
* **그림(비트맵):** **파일 → 가져오기 → 이미지 가져오기…**(File → Import → Import image…)(또는 PNG, JPG, BMP, GIF, WebP 파일을 창에 끌어 놓기)는 가져오기 대화 상자를 엽니다: 회전, 뒤집기, 밝기, 대비, 감마, 자동 레벨, 반전, 크기. **이미지 조정…**(Adjust image…)(**속성** 탭의 *이미지*(Image) 섹션 또는 **정렬 → 이미지 조정…**)은 페이지의 그림을 바꾸고, **이미지 트레이스…**(Trace image…)(같은 섹션 또는 **정렬 → 이미지 트레이스…**)는 어두운(또는 밝은) 영역을 윤곽선으로 바꿉니다(임계값, 얼룩 필터, 단순화, 곡선 다듬기). 이 윤곽선은 다른 도형처럼 그려집니다. **정렬 → 스타일 트레이스…**(Arrange → Style trace…)는 그림을 21가지 스타일 중 하나의 선으로 다시 그립니다(구불구불한 선, 나선, 점묘, 해칭, 흐름선, 한붓그리기 선…). [스타일 트레이스](Style-Trace-KO)를 참조하십시오.
* **이미지 편집…**(Edit image…)(**정렬** 메뉴, 마우스 오른쪽 버튼 메뉴, 또는 **그림 스타일**(Picture styles) 탭의 주황색 버튼)은 선택한 그림의 사진 편집기를 엽니다: **브러시**(brush), **지우개**(eraser)(흰색으로 칠함), **복제 도장**(clone stamp)(Ctrl+클릭, Mac에서는 Cmd+클릭으로 복사할 위치를 지정한 다음 칠함), 클릭한 곳 주변의 비슷한 회색 영역을 채우는 **채우기**(fill). 회색조만 다루며 크기, 경도, 불투명도, 허용 오차, 실행 취소와 다시 실행이 있습니다. 휠로 확대/축소하고, 오른쪽이나 가운데 버튼으로 그림을 옮깁니다. 도면은 **적용**(Apply)을 눌러야 바뀝니다.
* **이미지로 변환…**(Convert to image…)(도형을 선택하고 그 안에 그림이 없을 때)은 도형을 그림 하나로 바꿉니다: 미리 보기, 해상도(DPI), 크기, 닫힌 도형 채우기, 선 너비. **변환 후 객체 삭제**(Delete the objects afterwards)는 도형을 지우고, **객체 숨기기**(Hide the objects)는 미리 보기에서만 윤곽선을 빼 줍니다.
* **이미지 트레이스**(Trace image)와 **스타일 트레이스**(Style trace) 창의 **그림 숨기기**(Hide the picture)는 미리 보기에 결과만 보여 줍니다.
* **선으로 그리는 그림:** 레이어에 그림을 놓으면 그 레이어가 그리기 방식 **그림**(Picture)으로 바뀌며(한 번만. 되돌릴 수 있습니다), 그러면 그림 자체가 레이어의 **그림 방식**(Picture method)에 따라 선으로 그려집니다: **디더링 행**(Dithered rows), **점**(Dots) 또는 **톤에 따른 해칭**(Hatching by tone). 다른 그리기 방식의 레이어에서는 그림이 표시만 되고 그려지지 않습니다. [레이어와 펜](Layers-and-Pens-KO#그리기-방식)을 참조하십시오.

## 배치, 복사, 생성

**삽입**(Insert) 메뉴에는 객체를 삽입하는 왼쪽 팔레트의 도구(**사각형 (R)**(Rectangle (R)), **타원 (E)**(Ellipse (E)), **삼각형 (Y)**(Triangle (Y)), **별 (S)**(Star (S)), **다각형 (G)**(Polygon (G)), **하트 (K)**(Heart (K)), **나선 (I)**(Spiral (I)), **선 (L)**(Line (L)), **폴리라인 / 펜 (P)**(Polyline / pen (P)), **텍스트 (T)**(Text (T)). 사용 중인 도구에는 체크 표시)가 있고, 그 다음에 **도형 생성…**(Generate shape…)(플러그인의 생성기)과 **온라인 클립아트…**(Online clipart…)가 있습니다.

**정렬**(Arrange) 메뉴의 명령(LightCreator, MillCreator, PenCreator에서 같음):

* **패스 자동 연결…**(Auto-join paths…)은 끝점 사이가 허용 오차보다 가까운 열린 패스를 연결합니다. **허용 오차로 패스 닫기…**(Close path with tolerance…)는 두 끝점이 그만큼 가까운 패스를 닫습니다. **도그본 / T본 모서리…**(Dogbone / T-bone corners…)는 둥근 비트가 닿도록 모든 날카로운 모서리에 홈을 추가합니다(밀링용입니다).
* **격자 배열…**(Grid array…)은 선택 항목을 행과 열로 복사합니다. **원형 배열…**(Circular array…)은 선택 항목의 중심 둘레에 *전체 각도*(Total angle)에 걸쳐 복사본을 놓습니다(360°는 한 바퀴 전체). 위치에 따라 회전하거나 이동만 합니다. 복사본은 최대 2000개까지 만듭니다.
* **패스를 따라 복사…**(Copy along path…): 도형을 선택한 다음 패스를 **마지막에** 선택합니다. 패스를 따라 *간격*(Distance)마다 복사본을 놓으며 패스 방향에 맞춰 회전할 수 있습니다. **패스 위 텍스트…**(Text on path…): 텍스트를 선택한 다음 패스를 마지막에 선택합니다. 텍스트의 윤곽선이 *시작*(Start) 위치부터 패스를 따라 휘어집니다(이후에는 텍스트가 아니라 윤곽선입니다).
* **도형으로 자르기…**(Trim by shape…): 선을 선택한 다음 닫힌 도형을 **마지막에** 선택합니다. 안쪽(또는 바깥쪽) 부분이 남고, 선이 그 윤곽선과 만나는 곳에서 잘립니다. **중복 제거**(Remove duplicates)는 같은 레이어에서 윤곽선이 같은 도형을 지웁니다(선택 항목 또는 도면 전체). **분리**(Break apart)는 윤곽선마다 도형 하나를 만듭니다. **단순화…**(Simplify…)는 선에서 *허용 오차*(Tolerance) 안에 있는 점을 없앱니다.
* **일련번호 텍스트…**(Serial text…): 텍스트를 선택합니다. 텍스트가 격자로 복사되며 `{n}`이 하나씩 증가합니다. 또는 **CSV 파일 읽기…**(Read a CSV file…)로 행마다 한 번씩 복사되며 `{1}`, `{2}`…가 열입니다. **바코드 / QR 코드…**(Barcode / QR code…)는 QR 코드나 Code 39 바코드를 활성 레이어에 윤곽선으로 놓습니다(펜으로 그릴 수 있을 만큼 크게 만드십시오).
* **도형 배치 최적화…**(Nest shapes…)는 선택한 도형을 페이지 모서리에서부터 *영역 너비*(Area width) × *영역 높이*(Area height) 영역에 *간격*(Distance)을 두고 촘촘히 배치합니다. **실제 윤곽선 기준**(By the real outlines)(기본값 켜짐)을 쓰면 실제 모양대로 배치합니다. 작은 부품은 큰 부품의 구멍에, L자는 다른 부품의 모서리에 들어가며, 그룹은 한 부품으로 유지되고, **회전**(Turning)은 부품을 반 바퀴, 4분의 1 바퀴 또는 8분의 1 바퀴씩 돌릴 수 있게 합니다. **들어가지 않는 것은 새 용지에**(What does not fit goes on new sheets)는 나머지를 새 용지에 놓습니다. 각 용지는 같은 레이어와 재료를 가진 새 탭입니다(저장해 두었다가 이 작업 다음에 실행하십시오). 이 옵션이 없으면 들어가지 않는 것은 원래 자리에 남습니다. 끄면 도형은 경계 상자 기준으로 행 단위로 배치됩니다(*회전 허용*(Allow turning)은 키가 큰 것을 눕힙니다). **측정…**(Measure…)은 선택 항목의 크기, 위치, 넓이, 길이를 보여 주며, 도형이 두 개면 그 사이 거리도 보여 줍니다.

**파일 → 내보내기 → 선택 영역을 SVG로 내보내기…** / **선택 영역을 DXF로 내보내기…**는 선택한 도형을 씁니다(아무것도 선택하지 않았으면 모두).

## 카메라 오버레이(보기 메뉴)와 트레이스 대화 상자

**보기 → 오버레이 가져오기…**(View → Overlay from…)는 사진, 도면 또는 스캔을 **도면 아래에** 놓거나(**그림 불러오기…**(Load picture…)), 장치 카메라의 실시간 영상을 놓습니다(**카메라 시작**(Start camera), **프레임 고정**(Freeze frame). 카메라 탭의 **오버레이**(Overlay) 버튼으로도 가능). **맞추기: 작업 영역에서 네 모서리 끌기**(Align: drag the four corners on the work area)를 체크하고 모서리를 재료나 작업 영역의 모서리로 끌어 놓거나(그림이 원근 변환으로 따라옵니다), 장치와 함께 보관되는 **기준점**(Reference points)을 입력합니다. **불투명도**(Opacity), **오버레이 표시**(Show overlay), **작업 영역으로 재설정**(Reset to work area), **좌우 뒤집기**(Flip H), **상하 뒤집기**(Flip V), **90° 회전**(Rotate 90°), **제거**(Remove)가 같은 창에 있으며, **보기 → 카메라 오버레이 표시**(View → Show camera overlay)로 보이거나 숨깁니다. 그림은 프로젝트와 함께 저장됩니다. **이미지 트레이스**(Trace image) 대화 상자에서는 스크롤 휠이나 **확대**(Zoom in), **축소**(Zoom out), **보기 재설정**(Reset view) 버튼으로 그림을 확대/축소할 수 있으며, 녹색 **트레이스**(Trace) 버튼이 윤곽선을 만듭니다.

## 사이드 패널

* 탭을 끌어 다른 위치에 놓습니다(순서는 기억되며 백업에도 들어갑니다). 탭 왼쪽의 작은 화살표는 패널을 숨깁니다. 탭 이름이 있는 좁은 띠가 남으며, 이름을 클릭하면 그 탭으로 패널이 열립니다.
* 탭: **속성**(Properties), **레이어**(Layers), **장치**(Device), **제어**(Control), **콘솔**(Console), **클립아트**(Clipart), **설명**(Description), **카메라**(Camera)(장치에 켜진 카메라가 있을 때), 그리고 설정이 있는 플러그인마다 탭 하나.

## 탭과 창

단계별 설명: [창과 탭](Panes-and-Tabs-KO).

열려 있는 모든 도면, **미리 보기**(Preview), 텍스트로 표시된 프로젝트의 G-code(**G-code 미리 보기: 이름.nc**(Preview G-code: name.nc)), 파일의 **G-code 분석**(G-code analysis), **카메라 보기**(Camera view)는 작업 영역 위의 **탭**입니다.

* **보기 → 분할 보기: 나란히**(View → Split view: side by side) 또는 **분할 보기: 위아래로**(Split view: one above the other)는 작업 영역을 최대 **세 개의 창**으로 나눕니다. **단일 보기**(Single view)는 모든 탭을 다시 하나로 모읍니다. 창마다 새 도면을 여는 **+**가 있는 자체 탭 바가 있습니다.
* **탭을 끌어** 다른 창에 놓습니다(또는 탭 바 안에서 다른 위치로). 또는 탭의 메뉴(오른쪽 클릭)를 사용합니다: **창 N으로 이동**(Move to pane N)(다른 창들, 그리고 자리가 있고 원래 창에 다른 탭이 남아 있으면 새 창), **별도 창에서 열기**(Open in a separate window)(미리 보기, G-code 텍스트, 카메라 보기용. 창은 위치를 기억하며, **기본 창으로 돌아가기**(Back to the main window)를 누르거나 창을 닫으면 탭이 되돌아옵니다), **탭 닫기**(Close tab). 탭을 가운데 버튼으로 클릭해도 닫힙니다.
* 두 창 사이의 선을 끌어 크기를 바꿉니다. 선을 더블 클릭하면 크기가 같아집니다.
* 창의 마지막 탭을 닫으면 그 창이 닫히고 나머지 창이 자리를 메웁니다.
* 아무것도 두 번 열리지 않습니다. 이미 열린 프로젝트를 열면 그 탭이 표시되며, 프로젝트마다 미리 보기 하나, 카메라 보기 하나, G-code 텍스트 하나가 있습니다.
* 도면 하나가 **활성** 도면입니다. 도구, 메뉴, 단축키는 그 도면에 작용합니다. 다른 창의 도면은 보기용으로 표시되며 자체 확대 비율이 있습니다. 클릭하면 활성 도면이 됩니다.
* 창 배치는 기억됩니다.

## G-code 텍스트 탭

**G-code 미리 보기**(Preview G-code)(**G-code 저장**(Save G-code) 옆의 버튼)는 프로젝트의 프로그램을 만들어(켜져 있는 포스트프로세서 포함) **탭에 텍스트로** 보여 줍니다. 색이 입혀지고(G와 M 단어, 축, 속도, 주석) 편집할 수 있습니다. 탭의 **G-code 저장**은 파일로 씁니다. **다시 만들기**(Make again)는 프로젝트에서 다시 만듭니다(편집 내용이 있으면 먼저 **편집 내용을 버릴까요?**(Lose the edits?)라고 묻습니다). **분석**(Analyse)은 공구 경로를 **G-code 분석** 탭에 보여 줍니다. 편집 내용이 있는 탭에는 *직접 변경됨*(Changed by hand)과 점이 표시되며, 닫을 때 저장할지 묻습니다. 편집 내용이 없으면 프로젝트를 저장하거나, 메모가 바뀌거나, 장치 설정이 바뀌거나, 포스트프로세서가 바뀐 뒤 텍스트가 자동으로 다시 만들어집니다. **설정 → 보기 옵션… → 저장 후 G-code 미리 보기**(Settings → View options… → Preview G-code after saving)(기본값 꺼짐)는 **G-code 저장**을 할 때마다 저장한 파일을 분석 화면에서 엽니다.

## 보기 옵션

**설정 → 보기 옵션…**(Settings → View options…)에는 주 격자와 보조 격자, 작업 영역과 그 주변 공간의 색, 선 굵기, 그리고 다음이 있습니다.

* **레이어 이름 표시**(Show layer names)(기본값 꺼짐): 작업 영역 아래 레이어 줄에서 도형이 있는 레이어의 색 옆에 이름을 씁니다(긴 이름은 잘리고 전체 이름은 도움말에 있습니다. 줄이 가득 차면 가로로 스크롤됩니다).
* **저장 후 G-code 미리 보기**(Preview G-code after saving)(기본값 꺼짐): 위를 참조하십시오.
* **변수 이름 표시**(Show variable names)(기본값 꺼짐): 사용자 G-code용 변수가 있는 모든 필드의 레이블 옆에 변수 이름을 기울임꼴과 괄호로 표시합니다. 예를 들어 장치 이름 옆에 *(machine_name)*, 레이어 이름 옆에 *(layer_name)*. 클릭하면 `{machine_name}`이 클립보드에 복사되어 사용자 G-code 상자에 바로 붙여 넣을 수 있습니다([기계 제어](Machine-Control-KO#작업-실행) 참조).

## 레이어 프리셋

레이어 설정 위의 **프리셋 저장…**(Save preset…)과 **프리셋 불러오기**(Load preset)는 **레이어 프리셋**(Layer presets) 창을 엽니다. 레이어의 펜 설정을 이름을 붙여 보관했다가 나중에 아무 레이어에나 적용합니다. [레이어와 펜](Layers-and-Pens-KO#레이어-프리셋)을 참조하십시오.

## 자, 선택, 노드 바

* **자 (M)**(Ruler (M)): 팔레트에서 **축소 (X)**(Zoom out (X)) 다음의 도구입니다. 한 점에서 다른 점으로 끌거나 두 점을 클릭합니다. 도면 위의 선이 길이, ΔX, ΔY, 각도를 프로그램 단위로 보여 줍니다. 도형의 노드 가까이 있는 점은 노드 자체를 잡습니다(그렇지 않으면 스냅이 켜져 있을 때 격자를 잡습니다). 도형의 직선 구간(사각형의 변, 선)을 클릭하면 그 구간을 측정합니다. 측정 결과는 다음 측정, **Esc** 또는 다른 도구를 고를 때까지 남아 있습니다. 도면은 아무것도 바뀌지 않습니다.
* **도구 사용 중 오른쪽 클릭**(도형, 펜, 노드 도구, 자…)은 **Esc**를 두 번 누른 것처럼 동작합니다. 아무것도 선택하지 않은 상태로 **선택 (V)**로 돌아갑니다. 펜으로 그리던 선은 먼저 마무리됩니다. 선택 도구에서는 오른쪽 클릭이 이전처럼 컨텍스트 메뉴를 엽니다.
* **여러 객체 선택:** 전체 선택 영역의 테두리 외에 객체마다 얇은 점선 테두리가 생깁니다.
* **노드 바**는 이름 뒤에 단축키를 보여 줍니다: **모서리 (C)**(Corner (C)), **직선으로 (L)**(To line (L)), **곡선으로 (S)**(To curve (S)), **노드 추가 (I)**(Add node (I)), **노드 삭제 (D)**(Delete node (D)), **둥글게 (R)**(Round (R)), **끊기 (B)**(Break (B)). **열기 / 닫기**(Open / close)는 없어졌습니다. **끊기 (B)**가 패스를 열고, 패스의 한쪽 끝을 다른 끝에 놓으면 패스가 닫힙니다.
* **만들지 않는 레이어**(출력이 꺼진 레이어)는 객체가 작업 영역 쪽으로 흐리게 표시됩니다.

## 미리 보기: 버튼과 치수

* 미리 보기 바의 옵션은 **버튼**입니다. 켜져 있는 동안 연한 파란색이며(카메라 보기 버튼처럼), 클릭하면 켜지거나 꺼집니다.
* **치수**(Dimensions)는 기술 도면처럼 작업의 크기를 보여 줍니다: 전체의 너비와 높이, 부품이 몇 개 있으면 각 부품의 너비와 높이, 그리고 원점이 그림 안에 있으면 전체가 기계 원점에서 얼마나 떨어져 있는지.

* **그림:** PNG, JPEG, BMP, GIF, WebP처럼 TIFF(`.tif`, `.tiff`)도 읽습니다.

## 작업 영역의 치수, 자, 노드 메뉴

* **치수**(Dimensions)(작업 영역 위 바에서 **공구 경로**(Toolpaths) 옆의 버튼)는 도면을 기술 도면처럼 보여 줍니다: 전체와 각 윤곽선(도형의 바깥쪽과 구멍을 각각 따로)의 너비와 높이, 둥근 것의 지름, 같은 것은 한 번만 표시(**4 × Ø 6**). 도면은 아무것도 바뀌지 않습니다.
* **자 (M)**(Ruler (M))는 도형의 노드(사각형으로 표시), 구간의 중점(마름모), 원이나 타원의 중심(원)을 잡습니다. 원을 클릭하면 중심에서 클릭한 점까지의 반지름과 지름을, 타원에서는 두 반지름과 그 점까지의 반지름을, 곡선에서는 길이를, 곡선이 원호이면 중심에서 클릭한 점까지 그린 반지름과 그 길이를 보여 줍니다.
* **노드 편집**(Node edit): 노드나 구간을 오른쪽 클릭하면 노드 바의 메뉴가 열립니다. **부드럽게**(Smooth)의 단축키는 **G**이며, **둥글게 (R)**의 반지름은 그 버튼 뒤에 있습니다.

## 단위

* **설정 → 프로그램 옵션… → 단위**(Settings → Program options… → Units)는 프로그램이 길이를 표시할 단위를 고릅니다: 밀리미터, 센티미터, 미터, 인치, 피트 또는 **장치와 같게**(As the device). **속성**의 크기, 자, 도면 위와 미리 보기의 **치수**, 기술 도면에 사용됩니다.
* **장치의 단위**(장치 창의 밀리미터 또는 인치)는 기계의 단위이며 G-code는 그 단위로 작성됩니다. 인치 장치는 **G20**과 함께 모든 길이와 이송 속도가 인치로, 밀리미터 장치는 **G21**과 밀리미터로 작성됩니다. 컨트롤러가 사용하는 단위인지 확인하십시오.
* 장치가 프로그램과 다른 단위계(인치 대 밀리미터)를 쓰면 치수와 자가 둘 다 보여 줍니다. 프로그램 단위가 먼저, 기계 단위가 괄호 안에 표시됩니다. 예: **25.4 mm [1.000"]**.

## 드래그 나이프

플로터는 펜 대신 **드래그 나이프**(drag knife)로 자를 수 있습니다(비닐, 종이, 카드, 스텐실). 장치 창의 **펜**(Pen) 페이지에서 **공구가 드래그 나이프임**(The tool is a drag knife)을 체크합니다.

* **나이프**(Knife): **나이프 라이브러리**의 나이프는 **날 끝 오프셋**(offset of the tip)(날 끝이 축 뒤로 얼마나 끌려가는지), 모서리 처리, 오버컷을 한꺼번에 설정합니다. 기본 제공 나이프는 30°, 45°, 60° 날(0.15, 0.25, 0.5 mm)과 CNC 기계 홀더에 끼우는 드래그 나이프입니다. 정확한 오프셋은 날 제조사가 알려 줍니다. **나이프 라이브러리…**(Knife library…)(**플로터 → 나이프 라이브러리…**(Plotter → Knife library…)에도 있음)는 라이브러리를 엽니다. 기본 제공 나이프는 바꿀 수 없지만 **복사**(Copy)로 이름, 값, 메모가 있는 내 나이프를 만들 수 있으며, 이는 프로그램 설정(과 그 백업)에 보관됩니다. 장치의 값은 장치 고유의 값으로 남습니다. 라이브러리를 바꿔도 이전에 그 나이프를 가져간 장치는 바뀌지 않습니다.
* 프로그램이 오프셋을 보정합니다. 축이 날 끝보다 앞서 가며, **이보다 날카로운 모서리는 돌아가기**(Turn round corners sharper than)(기본값 15°)보다 날카로운 모서리에서는 작은 호를 그리며 모서리를 돌아, 날이 제자리에서 돌고 모서리가 날카롭게 유지됩니다. 모든 절단은 직전 절단 후 날이 향하던 방향에서 날을 돌리며 시작하고, 닫힌 윤곽선은 **시작점 지나서 더 자르기**(Cut on past the start)(0.5 mm)만큼 시작점을 지나 더 잘라서 닫히게 합니다.
* 구멍은 그것을 둘러싼 부품보다 먼저 잘리므로, 부품은 잘려 나갈 때까지 붙잡혀 있습니다. 나이프는 윤곽선만 자릅니다. 채우기와 그림은 빠지며(미리 보기에 표시됩니다), 오프셋의 약 네 배보다 작은 윤곽선은 둥글게 나옵니다(경고).
* **커터가 직접 오프셋을 보정함**(The cutter makes good the offset itself): 대부분의 비닐 커터(HPGL)는 컨트롤러에서 보정합니다. 체크하면 윤곽선이 그려진 그대로 잘립니다.
* 날은 펜처럼 내려가고 올라갑니다. Z축이면 **내림**(down)이 절삭 깊이입니다.
* 미리 보기는 축의 경로를 회색으로, 날 끝이 자르는 것을 레이어 색으로 그립니다.

아직 실제 커터에서는 시험하지 않았습니다. 첫 절단은 여분의 재료에 해 보십시오. 나이프 라이브러리와 커터의 HPGL 명령을 포함한 전체 설명: [드래그 나이프](Drag-Knife-KO).
