# 项目文件

PenCreator 保存 **`.cre`** 文件，这是 baseCreator 的项目文件，LightCreator 和 MillCreator 也写入这种文件：一个 JSON 文件，包含绘图、描述以及 **每个程序一个部分**（`laser`、`mill`、`pen`）。每个程序只写入自己的部分，并保持其他程序的部分不变，因此项目可以在程序之间传递而不会丢失任何内容。

`pen` 部分保存 64 个图层（名称、颜色、是否显示和是否绘制、绘制方式、笔库中的笔、笔宽、速度、填充间距和角度、交叉线、绘制次数、图片方法和抖动、在作业顺序中的位置）、**图层所使用的你自己的笔**（这样在另一台计算机上打开项目时会把它们一起带过去；它们会加入那里的 **我的笔**（My pens）），以及创建项目时所用绘图仪的记录（其名称和纸张尺寸）；当你在纸张尺寸不同的设备上打开项目时，状态行会提示。编号超出范围的图层会被默认图层替换。

描述（**描述**（Description）标签页）是项目的一部分；PenCreator 还会把它以 `(Note: …)` 行写入 G-code。有文件的项目会在更改后大约 20 秒自动保存到该文件（参见[设置与文件](Settings-and-Files-ZH)）。在 LightCreator 或 MillCreator 中创建的项目在这里打开时，会带有其绘图和描述以及默认的笔；保存时，它们的部分会按原样写回。容器格式（或 `pen` 部分）比程序所知的更新的文件会被拒绝，并显示消息。
