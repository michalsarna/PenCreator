# Third-party assets

PenCreator itself carries only its own icon (`icons/`, `pencreator.ico`, `pencreator.icns`, `pencreator.desktop`).
The fonts, the interface icons and the clipart pictures are embedded from [baseCreator](https://github.com/michalsarna/baseCreator),
see its [`assets/LICENSES.md`](https://github.com/michalsarna/baseCreator/blob/main/assets/LICENSES.md):

| What | Source | License |
|------|--------|---------|
| Interface fonts (Noto Sans, Sans Mono, Devanagari, SC) | [Noto fonts](https://fonts.google.com/noto) | SIL Open Font License 1.1 |
| Interface icons | [Lucide](https://lucide.dev) | ISC |
| Clipart pictures | [Material Design Icons](https://github.com/Templarian/MaterialDesign-SVG) by Pictogrammers | Apache License 2.0 |
| Icon of PenCreator | drawn for PenCreator from the icon of baseCreator | same license as PenCreator |
