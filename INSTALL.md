# Installing PenCreator

Every release on the [Releases page](https://github.com/michalsarna/PenCreator/releases) holds packages and archives for
each system and `SHA256SUMS.txt` to verify them.

| System | Installer / package | Archive |
|---|---|---|
| Windows 10/11 (64-bit) | `pencreator-vX.Y.Z-windows-x86_64-setup.exe` | `pencreator-vX.Y.Z-windows-x86_64.zip` |
| macOS, Apple silicon | `pencreator-vX.Y.Z-macos-arm64.dmg` | – |
| macOS, Intel | `pencreator-vX.Y.Z-macos-x86_64.dmg` | – |
| Debian / Ubuntu, x86_64 | `pencreator-vX.Y.Z-linux-amd64.deb` | `pencreator-vX.Y.Z-linux-x86_64.tar.gz` |
| Debian / Ubuntu, ARM64 | `pencreator-vX.Y.Z-linux-arm64.deb` | `pencreator-vX.Y.Z-linux-arm64.tar.gz` |

Details for each system (SmartScreen, Gatekeeper, libraries on Linux) are on the wiki page
[Installation](https://github.com/michalsarna/PenCreator/wiki/Installation).
